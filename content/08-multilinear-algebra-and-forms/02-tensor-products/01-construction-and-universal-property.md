## Construction and universal property

### Overview

A bilinear map $f : M \times N \to P$ is not linear on the module $M \times N$ (Chapter 1, Section 1). The tensor product $M \otimes_R N$ is a new module, built from $M$ and $N$, with a bilinear map $(m, n) \mapsto m \otimes n$ through which every bilinear map factors in exactly one way by a linear map. So bilinear maps become linear maps on $M \otimes_R N$.

This section builds the tensor product as a quotient of a free module, proves its universal property and its uniqueness, and computes $\mathbb{Z}/m \otimes_{\mathbb{Z}} \mathbb{Z}/n \cong \mathbb{Z}/\gcd(m, n)$, so that $\mathbb{Z}/2 \otimes \mathbb{Z}/3 = 0$. It uses Volume 7, Chapter 1.

### Definitions

Fix a commutative ring $R$ and $R$-modules $M$ and $N$.

**Definition (Tensor product).** A tensor product of $M$ and $N$ is a module $T$ with a bilinear map $\otimes : M \times N \to T$, $(m, n) \mapsto m \otimes n$, such that for each module $P$ and each bilinear map $f : M \times N \to P$ there is exactly one linear map $\bar f : T \to P$ with $\bar f(m \otimes n) = f(m, n)$ for all $m, n$.

This is the universal property. An element $m \otimes n$ is a pure tensor. The construction below shows that $T$ exists.

**Definition (The construction).** Let $F$ be the free $R$-module with basis the set $M \times N$; write $[m, n]$ for the basis vector of the pair $(m, n)$. Let $K \subseteq F$ be the submodule generated by all elements
$$[m + m', n] - [m, n] - [m', n], \quad [m, n + n'] - [m, n] - [m, n'], \quad [c m, n] - c [m, n], \quad [m, c n] - c [m, n].$$
Put $M \otimes_R N = F / K$ and let $m \otimes n$ be the class of $[m, n]$.

The four kinds of generators of $K$ are the four rules of bilinearity. In the quotient they hold by force:
$$(m + m') \otimes n = m \otimes n + m' \otimes n, \quad m \otimes (n + n') = m \otimes n + m \otimes n', \quad (c m) \otimes n = c (m \otimes n) = m \otimes (c n).$$
So the map $(m, n) \mapsto m \otimes n$ is bilinear. As for each bilinear map, $0 \otimes n = m \otimes 0 = 0$.

### Theorems and proofs

**Theorem (Universal property).** The module $M \otimes_R N = F / K$ with the map $(m, n) \mapsto m \otimes n$ is a tensor product of $M$ and $N$.

*Proof.* Let $f : M \times N \to P$ be bilinear. A linear map on a free module may take arbitrary values on the basis (Volume 7, Chapter 2), so there is a linear map $g : F \to P$ with $g([m, n]) = f(m, n)$. The map $g$ vanishes on each generator of $K$; for example $g([m + m', n] - [m, n] - [m', n]) = f(m + m', n) - f(m, n) - f(m', n) = 0$, and the other three cases are the other three rules of bilinearity. So $g$ vanishes on $K$, and it factors through the quotient: there is a linear $\bar f : F / K \to P$ with $\bar f(m \otimes n) = g([m, n]) = f(m, n)$. For uniqueness, the classes $m \otimes n$ generate $F / K$, since the $[m, n]$ generate $F$. Two linear maps that agree on a generating set are equal. $\square$

**Proposition (Pure tensors generate).** Each element of $M \otimes_R N$ is a finite sum $\sum_k m_k \otimes n_k$. Two linear maps on $M \otimes_R N$ that agree on all pure tensors are equal.

*Proof.* An element of $F$ is a finite sum $\sum_k c_k [m_k, n_k]$. Its class is $\sum_k c_k (m_k \otimes n_k) = \sum_k (c_k m_k) \otimes n_k$. The second claim is the uniqueness step of the theorem. $\square$

**Proposition (Uniqueness).** Let $(T, \otimes)$ and $(T', \otimes')$ be two tensor products of $M$ and $N$. There is exactly one linear map $\varphi : T \to T'$ with $\varphi(m \otimes n) = m \otimes' n$, and it is an isomorphism.

*Proof.* The universal property of $T$, applied to the bilinear map $\otimes'$, gives exactly one $\varphi$. In the same way there is a $\psi : T' \to T$ with $\psi(m \otimes' n) = m \otimes n$. The map $\psi \circ \varphi : T \to T$ is linear and sends $m \otimes n$ to $m \otimes n$. So does the identity. By the uniqueness in the universal property, for the bilinear map $\otimes$ itself, $\psi \circ \varphi = \mathrm{id}$. In the same way $\varphi \circ \psi = \mathrm{id}$. $\square$

Later proofs use only the universal property and the fact that pure tensors generate.

**Theorem (Linear maps on the tensor product).** The map $f \mapsto \bar f$ is an isomorphism of $R$-modules from the bilinear maps $M \times N \to P$ to $\operatorname{Hom}_R(M \otimes_R N, P)$. Its inverse sends $g$ to $(m, n) \mapsto g(m \otimes n)$.

*Proof.* For a linear $g$, the map $(m, n) \mapsto g(m \otimes n)$ is bilinear, as the composition of a bilinear map with a linear map. The two maps are inverse: $\overline{f}(m \otimes n) = f(m, n)$, and $g$ and $\overline{g(\cdot \otimes \cdot)}$ agree on pure tensors, so they are equal. The map $g \mapsto g(\cdot \otimes \cdot)$ is linear. $\square$

**Proposition (Symmetry).** There is exactly one linear map $M \otimes_R N \to N \otimes_R M$ with $m \otimes n \mapsto n \otimes m$, and it is an isomorphism.

*Proof.* The map $(m, n) \mapsto n \otimes m$ is bilinear, so the universal property gives the map. The same argument gives a map back with $n \otimes m \mapsto m \otimes n$. Both compositions fix the pure tensors, so they are the identities. $\square$

### Examples

**Example ($\mathbb{Z}/2 \otimes \mathbb{Z}/3 = 0$).** Over $\mathbb{Z}$, take $a \in \mathbb{Z}/2$ and $b \in \mathbb{Z}/3$. Then
$$a \otimes b = 3 (a \otimes b) - 2 (a \otimes b) = a \otimes 3 b - 2 a \otimes b = a \otimes 0 - 0 \otimes b = 0.$$
All pure tensors are $0$, and they generate, so $\mathbb{Z}/2 \otimes_{\mathbb{Z}} \mathbb{Z}/3 = 0$. The tensor product of two nonzero modules can be zero. This matches the counterexample of Chapter 1, Section 2: every bilinear map on $\mathbb{Z}/2 \times \mathbb{Z}/3$ is zero.

**Example ($\mathbb{Z}/m \otimes \mathbb{Z}/n$).** Let $m, n \ge 1$ and $d = \gcd(m, n)$. Then $\mathbb{Z}/m \otimes_{\mathbb{Z}} \mathbb{Z}/n \cong \mathbb{Z}/d$, with $1 \otimes 1 \mapsto 1$.

*Proof.* Put $t = 1 \otimes 1$. For integers $a, b$, $\bar a \otimes \bar b = a b (1 \otimes 1)$, so $t$ generates the group, which is cyclic. Next $m t = \bar m \otimes 1 = 0$ and $n t = 1 \otimes \bar n = 0$. By Bezout $d = u m + v n$ for integers $u, v$, so $d t = 0$. Thus the group has at most $d$ elements. For the converse, define $\beta(\bar a, \bar b) = a b \bmod d$. It is well defined: if $a \equiv a' \pmod m$, then $d \mid m \mid (a - a') b$, and in the same way for $b$. It is bilinear, and the induced linear map $\bar\beta$ sends $t$ to $1 \in \mathbb{Z}/d$. So $\bar\beta$ is onto $\mathbb{Z}/d$, and the cyclic group generated by $t$ has at least $d$ elements. Hence it has exactly $d$ elements, and $\bar\beta$ is an isomorphism. $\square$

For $m = 2$, $n = 3$ this gives $d = 1$ and the first example. For $m = 4$, $n = 6$ it gives $\mathbb{Z}/4 \otimes \mathbb{Z}/6 \cong \mathbb{Z}/2$.

**Counterexample (The ring matters).** In $\mathbb{C} \otimes_{\mathbb{C}} \mathbb{C}$, the scalar $i$ moves across: $i \otimes i = i^2 (1 \otimes 1) = -1 \otimes 1$. In $\mathbb{C} \otimes_{\mathbb{R}} \mathbb{C}$ this fails. The map $(z, w) \mapsto z \bar w$ is $\mathbb{R}$-bilinear but not $\mathbb{C}$-bilinear. Its induced $\mathbb{R}$-linear map sends $i \otimes i$ to $i \cdot (-i) = 1$ and $(-1) \otimes 1$ to $-1$. So $i \otimes i \neq (-1) \otimes 1$ over $\mathbb{R}$. The notation $\otimes_R$ must name the ring. Section 4 computes $\mathbb{C} \otimes_{\mathbb{R}} \mathbb{C} \cong \mathbb{C} \times \mathbb{C}$.

### The library around it

Functoriality, associativity and the units $R \otimes M \cong M$ are in Section 2. Section 3 shows that $e_1 \otimes e_1 + e_2 \otimes e_2 \in K^2 \otimes K^2$ is not a pure tensor. In a proof, the usual first step on an element is `induction x using TensorProduct.inductionOn`, and for linear maps it is `ext`.

### Exercises

1. (A) Compute $\mathbb{Z}/6 \otimes_{\mathbb{Z}} \mathbb{Z}/9$ and $\mathbb{Z}/5 \otimes_{\mathbb{Z}} \mathbb{Z}/7$. Hint: the gcd formula.
2. (A) In $\mathbb{Z}/4 \otimes_{\mathbb{Z}} \mathbb{Z}/6$, decide whether $\bar 2 \otimes \bar 1$ and $\bar 1 \otimes \bar 3$ are zero. Hint: both equal a multiple of $1 \otimes 1$; compute modulo $2$.
3. (B) Show that $R \otimes_R M \cong M$ by $c \otimes m \mapsto c m$. Hint: the inverse is $m \mapsto 1 \otimes m$.
4. (B) Show that $\mathbb{Q} \otimes_{\mathbb{Z}} \mathbb{Z}/n = 0$. Hint: $q \otimes a = n (q / n) \otimes a = (q / n) \otimes n a$.
5. (B) Show that $x \otimes y + y \otimes x$ in $K^2 \otimes K^2$ is a pure tensor only if $x$ and $y$ are linearly dependent. Hint: the map $x \otimes y \mapsto x y^{\mathsf{T}}$ and a determinant.
6. (C) Let $T$ be a module with a bilinear map $\otimes'$ whose image spans $T$, and assume each bilinear map on $M \times N$ factors through $T$ by some linear map. Show that $T$ is a tensor product. Hint: the factorization is unique because the image spans.

### Notes and history

The universal property is the definition that the rest of the theory uses; the quotient is only a proof of existence.
