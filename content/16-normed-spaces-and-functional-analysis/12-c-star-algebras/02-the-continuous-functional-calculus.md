## The continuous functional calculus

### Overview

Let $a$ be a normal element of a unital C*-algebra $A$, that is $a^* a = a a^*$. The continuous functional calculus defines $f(a) \in A$ for each continuous function $f$ on the spectrum $\sigma(a)$, so that $f \mapsto f(a)$ is a star homomorphism from $C(\sigma(a))$ to $A$ that sends the identity function to $a$. For a polynomial $f$, the value $f(a)$ is the usual polynomial in $a$ and $a^*$. The theorem says that this map exists, that it is an isometry, and that its image is the closed star subalgebra generated by $a$.

The proof uses the commutative Gelfand theory of Chapter 9. Let $B$ be the closed star subalgebra generated by $1$ and $a$. It is commutative because $a$ is normal. Each character $\varphi$ of $B$ is determined by the number $\varphi(a)$, which is in $\sigma_B(a)$, and each point of $\sigma_B(a)$ comes from a character. So the character space of $B$ is homeomorphic to $\sigma_B(a)$, and the Gelfand transform is a star isomorphism $B \cong C(\sigma_B(a))$. The Gelfand transform is isometric because the norm of a normal element is its spectral radius, as Section 1 shows. Spectral permanence says that $\sigma_B(a) = \sigma_A(a)$. The inverse of the Gelfand transform is the functional calculus.

The functional calculus has three properties that make it a computation tool. The spectral mapping theorem says $\sigma(f(a)) = f(\sigma(a))$. Composition is $(g \circ f)(a) = g(f(a))$. The map is unique: two continuous star homomorphisms from $C(\sigma(a))$ that agree on the identity function agree everywhere, by the Stone Weierstrass theorem. Uniqueness also gives naturality: a star homomorphism $\varphi : A \to B$ satisfies $\varphi(f(a)) = f(\varphi(a))$.

With $f$ real valued, $f(a)$ is self-adjoint. With $f \ge 0$, it is positive. With $f$ of modulus $1$, it is unitary, and with $f$ taking values in $\{0, 1\}$, it is a projection. This is how Mathlib defines square roots, absolute values, positive and negative parts, and the other functions of an operator in Section 3.

### The library around it

Mathlib does not define the calculus only for normal elements of complex C*-algebras. The file `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Unital` defines a class `ContinuousFunctionalCalculus R A p` with a scalar ring `R` and a predicate `p` on `A`. An instance says that for each `a` with `p a` there is a continuous star homomorphism `cfcHom` from `C(spectrum R a, R)` to `A` that is a closed embedding, sends the identity to `a`, and satisfies the spectral mapping theorem. There are three standard instances: `R = ℂ` with `p = IsStarNormal`, `R = ℝ` with `p = IsSelfAdjoint`, and `R = ℝ≥0` with `p = (0 ≤ ·)`. The library note `LibraryNote.continuous_functional_calculus` in `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Note` explains this design.

The main user function is `cfc f a`, which takes any `f : R → R` and any `a : A`. The definition uses `cfcHom` when `p a` holds and `f` is continuous on the spectrum, and returns `0` otherwise, by `cfc_apply_of_not_predicate` and `cfc_apply_of_not_continuousOn`. So `cfc` is a total function, and its lemmas carry the conditions as auto parameters, which a tactic of the library proves in most cases. The algebra lemmas are `cfc_id`, `cfc_add`, `cfc_mul`, `cfc_pow`, `cfc_star` and `cfc_comp`, which is `cfc (g ∘ f) a = cfc g (cfc f a)`, with variants such as `cfc_comp_pow`. The lemma `cfc_map_spectrum` is the spectral mapping theorem. The lemma `cfc_congr` says that `cfc f a` depends only on the values of `f` on the spectrum, and `cfc_eq_cfc_iff_eqOn` is the converse. The lemma `isUnit_cfc_iff` says that `cfc f a` is invertible if and only if `f` has no zero on the spectrum. For order, `cfc_mono` compares two functions on the spectrum. The lemma `cfc_predicate` says that `p (cfc f a)` always holds, so for example `IsSelfAdjoint.cfc` holds for real functions. The lemma `cfcHom_id` says that `cfcHom` sends the restricted identity to `a`, and `cfcHom_isClosedEmbedding` gives the closed embedding.

The file `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.NonUnital` defines the version `cfcₙ` for algebras that need not have a unit. It uses the quasispectrum instead of the spectrum, and it applies only to functions with `f 0 = 0`, which form the algebra of `ContinuousMapZero`. The lemma `CFC.quasispectrum_zero_eq` computes one example, and `cfcₙ_eq_cfc` says that the two calculi agree when both apply.

The file `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Basic` constructs the complex instance by the Gelfand argument of the overview. The equivalence `continuousFunctionalCalculus` sends `C(spectrum ℂ a, ℂ)` onto `StarAlgebra.elemental ℂ a`, the closed star subalgebra generated by `a`. The homeomorphism `StarAlgebra.elemental.characterSpaceHomeo` identifies the character space of this subalgebra with the spectrum. The instance `IsStarNormal.instContinuousFunctionalCalculus` is the result for normal elements. The file `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Instances` derives the real and nonnegative instances, `IsSelfAdjoint.instContinuousFunctionalCalculus` and `Nonneg.instContinuousFunctionalCalculus`, together with their non-unital forms. The lemmas `cfc_real_eq_complex` and `cfc_nnreal_eq_real` relate the three calculi.

The derivation uses the file `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Restrict`. The predicate `SpectrumRestricts a f` says that the spectrum of `a` over a larger field is the image of a spectrum over a smaller field under `f`, for example that the complex spectrum of a self-adjoint element is real. The theorem `SpectrumRestricts.cfc` builds a calculus over the smaller field from a calculus over the larger one, and `SpectrumRestricts.cfc_eq_restrict` says that the two agree.

Uniqueness is in `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Unique`. The class `ContinuousMap.UniqueHom R A` says that two continuous star homomorphisms from `C(s, R)` to `A` that agree on the identity are equal, and the instances `Complex.instContinuousMapUniqueHom`, `Real.instContinuousMapUniqueHom` and `NNReal.instContinuousMap.UniqueHom` prove it with the Stone Weierstrass theorem. The consequence `StarAlgHom.map_cfc` is naturality, `φ (cfc f a) = cfc f (φ a)` for a continuous star homomorphism `φ`, and `NonUnitalStarAlgHom.map_cfcₙ` is the form for `cfcₙ`.

The other files hold short results. In `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Commute`, `Commute.cfc` says that if `b` commutes with `a` and with `star a`, then it commutes with `cfc f a`, and `IsSelfAdjoint.commute_cfc` is the form for self-adjoint `a`. In `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Pi`, `cfc_map_pi` and `cfc_map_prod` compute the calculus in products coordinate by coordinate. In `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Transfer`, `ContinuousFunctionalCalculus.transfer` moves an instance along a continuous star algebra equivalence, which is useful for type synonyms. In `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Range`, `cfc_mem_elemental` and `range_cfc` say that the values of `cfc · a` form the closed star subalgebra generated by `a`. In `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Unitary`, `cfc_unitary_iff` says that `cfc f a` is unitary if and only if $|f| = 1$ on the spectrum, and `unitary_iff_isStarNormal_and_spectrum_subset_unitary` characterizes unitaries as the normal elements with spectrum on the circle. In `Mathlib.Analysis.CStarAlgebra.ContinuousFunctionalCalculus.Projection`, `isIdempotentElem_iff_spectrum_subset` says that an element in the domain of the calculus is idempotent if and only if its spectrum is in $\{0, 1\}$, and `isIdempotentElem_star_mul_self_iff_isIdempotentElem_self_mul_star` says that $x^* x$ is idempotent if and only if $x x^*$ is.

A short proof shows the method. To prove that a self-adjoint `a` with spectrum in $\{0, 1\}$ is idempotent, write $a = $ `cfc id a` by `cfc_id`. Then $a^2 = $ `cfc (fun x ↦ x ^ 2) a` by `cfc_pow`, and since $x^2 = x$ on $\{0, 1\}$, `cfc_congr` gives $a^2 = a$.

#### Common errors

1. `cfc f a` returns `0` when `f` is not continuous on the spectrum or when `p a` fails. A goal can then become an equation `0 = 0` that is true but useless. Check the hypotheses before rewriting with a lemma that has auto parameters.
2. The scalar ring is part of the term: `cfc (f : ℝ → ℝ) a` and `cfc (g : ℂ → ℂ) a` use different instances. Use `cfc_real_eq_complex` to move between them, not unfolding of definitions.
3. `cfcₙ` needs `f 0 = 0`. A function such as `fun x ↦ x + 1` gives `0` under `cfcₙ`, even in a unital algebra. Use `cfc` there.

### Exercises

1. (A) Prove that `cfc (fun _ ↦ 1) a = 1` for a normal element `a` of a unital C*-algebra, with `cfc_congr` and the lemmas on constants.
2. (A) Show that `cfc f a` is self-adjoint for each `f : ℝ → ℝ`, with `cfc_predicate`.
3. (B) Prove that the spectrum of `cfc (fun x ↦ x ^ 2) a` is the set of squares of the spectrum of `a`, with `cfc_map_spectrum`.
4. (B) Prove that a normal element whose spectrum is on the unit circle is unitary, with `cfc_unitary_iff` and `cfc_id`.
5. (B) Show that if `b` commutes with a self-adjoint `a`, then `b` commutes with `cfc f a` for each real `f`, with `IsSelfAdjoint.commute_cfc`.
6. (C) Prove that a normal element with real spectrum is self-adjoint. Use `cfc_star` with the identity function and the fact that `star z = z` for real `z`.
