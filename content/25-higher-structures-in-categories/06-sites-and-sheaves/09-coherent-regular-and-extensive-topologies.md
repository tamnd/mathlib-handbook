## Coherent, regular and extensive topologies

### Overview

Some categories carry a Grothendieck topology that comes only from their own colimits. The covers are the families of morphisms that are jointly surjective in the categorical sense. The library calls a family $\pi_a : X_a \to B$ an effective epimorphic family, `EffectiveEpiFamily X π`, when $B$ is the colimit of the diagram of the $X_a$ and their pairwise "overlaps". A single morphism with this property is an effective epimorphism, `EffectiveEpi f`. Three topologies use these notions. The coherent topology has the finite effective epimorphic families as covers. The regular topology has the single effective epimorphisms as covers. The extensive topology has the finite coproduct inclusions as covers.

These topologies are the base of condensed mathematics. On the category of compact Hausdorff spaces, or on the profinite sets, the coherent topology is the topology of finite jointly surjective families. The sheaves on these sites are the condensed objects. The 15 modules of this section give the three topologies, the sheaf conditions for them in concrete terms, the comparison between them, and the transfer of the sheaf categories along functors and equivalences.

The section uses the sieves and the sheaf condition of the first two sections of this chapter, the limits and colimits of Volume 24, and projective objects from Chapter 2. Chapter 7, Section 2, treats extensive and regular categories in their own right. This section needs only the classes `FinitaryPreExtensive` and `FinitaryExtensive`.

### The library around it

**The three topologies.** The module `Mathlib.CategoryTheory.Sites.Coherent.Basic` defines two classes and three coverages. The class `Precoherent C` says that finite effective epimorphic families pull back in a weak sense. Its field `Precoherent.pullback` says: for a finite effective epimorphic family $\pi_a : X_a \to B_1$ and a morphism $f : B_2 \to B_1$, there is a finite effective epimorphic family $X'_b \to B_2$ such that each $X'_b \to B_2 \to B_1$ factors through some $X_a$. The class `Preregular C` is the same condition for single effective epimorphisms. For an effective epi $h : X \to B_1$ and $f : B_2 \to B_1$, there is an effective epi $W \to B_2$ and a morphism $W \to X$ that make the square commute. Neither class asks for pullbacks.

From these classes the module builds `coherentCoverage C`, `regularCoverage C` and `extensiveCoverage C`. The topologies `coherentTopology C`, `regularTopology C` and `extensiveTopology C` are the Grothendieck topologies that these coverages generate. The extensive coverage needs `FinitaryPreExtensive C`, so that finite coproducts are stable under pullback.

The coverage gives covering presieves, but the topology contains all sieves that are generated by them and then saturated. Three modules give a direct description of the covering sieves:

| Lean name | A sieve $S$ on $X$ covers if and only if |
| --- | --- |
| `coherentTopology.mem_sieves_iff_hasEffectiveEpiFamily` | $S$ contains a finite effective epimorphic family |
| `regularTopology.mem_sieves_iff_hasEffectiveEpi` | $S$ contains one effective epimorphism $Y \to X$ |
| `extensiveTopology.mem_sieves_iff_contains_colimit_cofan` | $S$ contains the inclusions of a finite coproduct cofan with vertex $X$ |

The proof for the coherent case uses `EffectiveEpiFamily.transitive_of_finite`: if $X_a \to B$ is a finite effective epimorphic family and each $X_a$ has a finite effective epimorphic family over it, then the composites form a finite effective epimorphic family over $B$. This makes the set of sieves that contain a finite effective epimorphic family transitive, so it is already a Grothendieck topology. The instance `regularTopology.instEffectiveEpiComp` does the same job for the regular case.

**Sheaves for the coherent topology.** The module `Mathlib.CategoryTheory.Sites.Coherent.CoherentSheaves` states the sheaf condition for a presheaf of types. By `isSheaf_coherent`, a presheaf $P$ is a sheaf for `coherentTopology C` if and only if it satisfies `Presieve.IsSheafFor` for the presieve of each finite effective epimorphic family. The instance `coherentTopology.subcanonical` says that each representable presheaf is a sheaf. This follows because a finite effective epimorphic family is a colimit, and a representable presheaf takes colimits to limits.

**Sheaves for the regular topology.** The module `Mathlib.CategoryTheory.Sites.Coherent.RegularSheaves` gives the sheaf condition in a form that has no sieves. The class `Presieve.regular` says that a presieve is generated by one effective epimorphism. For a presheaf $F : C^{op} \to D$, the predicate `regularTopology.EqualizerCondition F` says the following: for each effective epi $\pi : X \to B$ with a kernel pair, the map $F(B) \to F(X)$ is an equalizer of the two maps $F(X) \rightrightarrows F(X \times_B X)$. The main result is `regularTopology.equalizerCondition_iff_isSheaf`. In a preregular category where each effective epi has a kernel pair, `EqualizerCondition F` holds if and only if $F$ is a sheaf for `regularTopology C`.

If all objects are projective, the regular condition is empty. Each effective epi onto a projective object has a section, and a presieve that contains a split epi satisfies the sheaf condition for every presheaf. The lemma `regularTopology.isSheafFor_regular_of_projective` states this for one presieve, and `regularTopology.isSheaf_of_projective` says that every presheaf is a regular sheaf when all objects are projective. The module also gives `regularTopology.equalizerCondition_of_natIso` and `regularTopology.equalizerCondition_precomp_of_preservesPullback` to move the condition along isomorphisms and along functors that preserve pullbacks.

**Sheaves for the extensive topology.** The module `Mathlib.CategoryTheory.Sites.Coherent.ExtensiveSheaves` has the class `Presieve.Extensive`, which says that a presieve is the set of inclusions of a finite coproduct. The theorem `Presheaf.isSheaf_iff_preservesFiniteProducts` says: in a finitary extensive category, a presheaf $F : C^{op} \to D$ is a sheaf for `extensiveTopology C` if and only if `PreservesFiniteProducts F`. In other words, $F$ takes finite coproducts in $C$ to finite products in $D$. The version for presheaves of types is `Presieve.isSheaf_iff_preservesFiniteProducts`.

The module `Mathlib.CategoryTheory.Sites.Coherent.ExtensiveColimits` uses this description. A colimit of functors that preserve finite products again preserves finite products if the functor `colim` preserves finite products. Thus `isSheaf_pointwiseColimit` says that a colimit of extensive sheaves, computed objectwise, is again a sheaf. Instances give this for all shapes when $A$ is preadditive.

**The comparison.** The module `Mathlib.CategoryTheory.Sites.Coherent.Comparison` relates the three topologies. If $C$ is preregular and finitary pre-extensive, then an instance makes $C$ precoherent. The theorem `extensive_regular_generate_coherent` says that the union of the extensive and the regular coverages generates `coherentTopology C`. The idea is that a finite family $X_a \to B$ is effective epimorphic exactly when $\coprod_a X_a \to B$ is an effective epi. So a coherent cover is a coproduct cover followed by a regular cover.

The module `Mathlib.CategoryTheory.Sites.Coherent.SheafComparison` turns this into a statement about sheaves. The theorem `Presheaf.isSheaf_coherent_iff_regular_and_extensive` says that a presheaf is a coherent sheaf if and only if it is both an extensive sheaf and a regular sheaf. Together with the results above, `Presheaf.isSheaf_iff_preservesFiniteProducts_and_equalizerCondition` gives a test with no sieves: in a finitary extensive preregular category, a presheaf is a coherent sheaf if and only if it preserves finite products and satisfies the equalizer condition. If also each object is projective, the regular part is automatic. Then `Presheaf.isSheaf_iff_preservesFiniteProducts_of_projective` says that the coherent sheaves are the presheaves that preserve finite products, and `Presheaf.coherentExtensiveEquivalence` is the resulting equivalence of the two sheaf categories. This is the case of extremally disconnected compact Hausdorff spaces in condensed mathematics.

**Change of site.** The same module compares sheaves on two categories. Let $F : C \to D$ be fully faithful, and let $D$ be precoherent. Assume that $F$ preserves and reflects finite effective epimorphic families, and that `Functor.EffectivelyEnough F` holds: each object of $D$ is the target of an effective epi from an object $F(W)$. Then `coherentTopology.equivalence F A` is an equivalence between the coherent sheaves on $C$ and on $D$ with values in $A$. The variant `coherentTopology.equivalence'` takes a finitary extensive preregular $D$ and asks $F$ only about single effective epis. The regular version is `regularTopology.equivalence`. The proofs use the dense subsites of Chapter 9 through the instances `coherentTopology.instIsDenseSubsite` and `regularTopology.instIsDenseSubsite`.

Two short modules show that the hypotheses on $C$ in this setting are not extra. With the same conditions on $F$, `Functor.reflects_precoherent` gives `Precoherent C` from `Precoherent D`, and `Functor.reflects_preregular` gives `Preregular C` from `Preregular D`. The module `Mathlib.CategoryTheory.Sites.Coherent.Equivalence` treats the case of an equivalence `e : C ≌ D`. Here `Equivalence.precoherent` and `Equivalence.preregular` transfer the classes, and `Equivalence.sheafCongrPrecoherent` and `Equivalence.sheafCongrPreregular` give equivalences of sheaf categories. The lemma `Equivalence.precoherent_isSheaf_iff_of_essentiallySmall` lets a user test the coherent sheaf condition on an essentially small site after a change to a small model.

**Local surjectivity and limits.** The module `Mathlib.CategoryTheory.Sites.Coherent.LocallySurjective` describes the locally surjective morphisms of presheaves with values in a concrete category. By `regularTopology.isLocallySurjective_iff`, a morphism $f : F \to G$ is locally surjective for the regular topology if and only if each $y \in G(X)$ lifts to some $x \in F(X')$ after restriction along an effective epi $X' \to X$. The lemma `coherentTopology.isLocallySurjective_iff` says that, on a finitary extensive preregular category, a morphism of coherent sheaves is locally surjective for the coherent topology if and only if it is locally surjective for the regular topology. By `extensiveTopology.isLocallySurjective_iff`, a morphism of extensive sheaves is locally surjective if and only if it is surjective on each object.

The module `Mathlib.CategoryTheory.Sites.Coherent.SequentialLimit` applies this. Assume that, in $C$, a sequential limit of effective epis is an effective epi. Then `coherentTopology.epi_π_app_zero_of_epi` says that for a sequence of epimorphisms of coherent sheaves of types $\cdots \to X_2 \to X_1 \to X_0$, the projection $\lim X_n \to X_0$ is an epimorphism.

#### Common errors

1. A user tries to use `coherentTopology C` with no instance `Precoherent C`. The definition needs the class, and Lean does not find it from `FinitaryExtensive C` alone. A user must supply `Preregular C` as well, so that the instance from `Mathlib.CategoryTheory.Sites.Coherent.Comparison` applies.
2. A user applies `regularTopology.equalizerCondition_iff_isSheaf` in a category that does not have the kernel pairs. The theorem asks for `HasPullback f f` for each effective epi $f$. Without the kernel pairs, `regularTopology.EqualizerCondition F` holds trivially for those morphisms and it is not the sheaf condition.
3. A user expects `Presheaf.isSheaf_iff_preservesFiniteProducts` to describe coherent sheaves. It describes only extensive sheaves. For coherent sheaves a user must add the equalizer condition, or use `Presheaf.isSheaf_iff_preservesFiniteProducts_of_projective` when all objects are projective.

### Exercises

1. (A) Use `coherentTopology.mem_sieves_iff_hasEffectiveEpiFamily` to show that the maximal sieve on $X$ is covering for `coherentTopology C`.
2. (A) Show that each representable presheaf is a sheaf for `regularTopology C` with the instance `regularTopology.subcanonical`.
3. (B) Show that a sieve that contains one effective epi is covering for `coherentTopology C` when $C$ is precoherent.
4. (B) Use `Presheaf.isSheaf_iff_preservesFiniteProducts` to show that a constant presheaf with value a terminal object is an extensive sheaf.
5. (C) Use `Presheaf.isSheaf_coherent_iff_regular_and_extensive` and `regularTopology.isSheaf_of_projective` to prove `Presheaf.isSheaf_iff_preservesFiniteProducts_of_projective`.
