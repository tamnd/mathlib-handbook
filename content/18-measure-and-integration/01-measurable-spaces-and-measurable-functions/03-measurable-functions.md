## Measurable functions

### Overview

A measurable function is the analogue of a continuous function: preimages of measurable sets are measurable. The integral of Chapter 4 needs a large class of them. This section proves that the class contains the continuous functions and that it is closed under the operations of analysis: sums, products, countable suprema and pointwise limits of sequences.

The main tool: measurability can be checked on a generating family.

### Definitions

**Definition (measurable function).** Let $(X, \Sigma_X)$ and $(Y, \Sigma_Y)$ be measurable spaces. A map $f : X \to Y$ is *measurable* if $f^{-1}(B) \in \Sigma_X$ for each $B \in \Sigma_Y$. When $X$ and $Y$ are topological spaces with their Borel σ-algebras, $f$ is *Borel measurable*.

**Definition (pull back and push forward).** Let $f : X \to Y$ be a map. For a σ-algebra $\Sigma_Y$ on $Y$, the *pull back* $f^* \Sigma_Y = \{f^{-1}(B) : B \in \Sigma_Y\}$ is a σ-algebra on $X$, because preimages commute with complements and unions. For $\Sigma_X$ on $X$, the *push forward* $f_* \Sigma_X = \{B \subseteq Y : f^{-1}(B) \in \Sigma_X\}$ is a σ-algebra on $Y$, for the same reason.

So $f$ is measurable if and only if $f^* \Sigma_Y \le \Sigma_X$, if and only if $\Sigma_Y \le f_* \Sigma_X$. The pull back is the smallest σ-algebra on $X$ for which $f$ is measurable.

::: mathlib

**Definition (product σ-algebra).** Let $(X_1, \Sigma_1)$ and $(X_2, \Sigma_2)$ be measurable spaces, with the projections $p_1, p_2$ of $X_1 \times X_2$. The *product σ-algebra* $\Sigma_1 \otimes \Sigma_2$ is $p_1^* \Sigma_1 \vee p_2^* \Sigma_2$, the smallest σ-algebra for which both projections are measurable. It is generated by the rectangles $A_1 \times A_2$ with $A_i \in \Sigma_i$, because $A_1 \times A_2 = p_1^{-1}(A_1) \cap p_2^{-1}(A_2)$.

::: mathlib

### Theorems and proofs

**Proposition (checking on generators).** Let $\Sigma_Y = \sigma(\mathcal{C})$ and let $f : X \to Y$ satisfy $f^{-1}(C) \in \Sigma_X$ for each $C \in \mathcal{C}$. Then $f$ is measurable.

*Proof.* The push forward $f_* \Sigma_X$ is a σ-algebra on $Y$, and it contains $\mathcal{C}$ by hypothesis. So it contains $\sigma(\mathcal{C}) = \Sigma_Y$, by Section 1. That is, $f^{-1}(B) \in \Sigma_X$ for each $B \in \Sigma_Y$. $\square$

::: mathlib

**Proposition (composition).** If $f : X \to Y$ and $g : Y \to Z$ are measurable, then $g \circ f$ is measurable.

*Proof.* $(g \circ f)^{-1}(B) = f^{-1}(g^{-1}(B))$, and $g^{-1}(B) \in \Sigma_Y$. $\square$

::: mathlib

**Theorem (continuous maps).** Let $X$ and $Y$ be topological spaces with their Borel σ-algebras. Each continuous map $f : X \to Y$ is measurable.

*Proof.* $\mathcal{B}(Y)$ is generated by the open sets, and $f^{-1}(U)$ is open for each open $U$, so it is in $\mathcal{B}(X)$. Apply the proposition on generators. $\square$

::: mathlib

**Corollary (real functions).** A map $f : X \to \mathbb{R}$ is measurable if and only if $\{x : f(x) < q\} \in \Sigma_X$ for each $q \in \mathbb{Q}$.

*Proof.* The sets $(-\infty, q)$ are Borel, which gives one direction. They generate $\mathcal{B}(\mathbb{R})$ by Section 1, which gives the other one. $\square$

**Proposition (maps into a product).** A map $f = (f_1, f_2) : X \to X_1 \times X_2$ is measurable for $\Sigma_1 \otimes \Sigma_2$ if and only if $f_1$ and $f_2$ are measurable.

*Proof.* If $f$ is measurable, so are $f_i = p_i \circ f$. Conversely, $f^{-1}(A_1 \times A_2) = f_1^{-1}(A_1) \cap f_2^{-1}(A_2) \in \Sigma_X$, and the rectangles generate $\Sigma_1 \otimes \Sigma_2$. $\square$

**Theorem (arithmetic).** Let $f, g : X \to \mathbb{R}$ be measurable. Then $f + g$, $f g$, $\max(f, g)$ and $c f$ for $c \in \mathbb{R}$ are measurable.

*Proof.* For the sum, let $a \in \mathbb{R}$. Then
$$\{f + g < a\} = \bigcup_{q \in \mathbb{Q}} \big(\{f < q\} \cap \{g < a - q\}\big).$$
If $f(x) + g(x) < a$, then $f(x) < a - g(x)$, and there is a rational $q$ with $f(x) < q < a - g(x)$, so $g(x) < a - q$. Conversely, $f(x) < q$ and $g(x) < a - q$ give $f(x) + g(x) < a$. The union is countable, so $f + g$ is measurable by the corollary. The map $t \mapsto c t$ is continuous, so $c f$ is measurable by composition, and so is $f - g = f + (-1) g$. For the square, $\{f^2 < a\}$ is empty for $a \le 0$ and equals $\{-\sqrt{a} < f < \sqrt{a}\}$ for $a > 0$, which is measurable. Then $f g = \tfrac14\big((f + g)^2 - (f - g)^2\big)$ is measurable. Finally $\{\max(f, g) < a\} = \{f < a\} \cap \{g < a\}$. $\square$

**Theorem (suprema and limits).** Let $f_n : X \to [-\infty, \infty]$ be measurable for $n \in \mathbb{N}$. Then $\sup_n f_n$, $\inf_n f_n$, $\limsup_n f_n$ and $\liminf_n f_n$ are measurable. If $f_n(x) \to f(x)$ for each $x$, then $f$ is measurable.

*Proof.* The rays $(a, \infty]$ generate the Borel sets of $[-\infty, \infty]$, by the argument of Section 1. For each $a$, $\sup_n f_n(x) > a$ if and only if $f_n(x) > a$ for some $n$, so $\{\sup_n f_n > a\} = \bigcup_n \{f_n > a\}$, a countable union. Then $\inf_n f_n = -\sup_n (-f_n)$. Next $\limsup_n f_n = \inf_n \sup_{k \ge n} f_k$, and each $\sup_{k \ge n} f_k$ is measurable, so the infimum is measurable. In the same way $\liminf_n f_n = \sup_n \inf_{k \ge n} f_k$. If the sequence converges, then $f = \limsup_n f_n$. $\square$

::: mathlib

**Theorem (limits in a metric space).** Let $(Y, d)$ be a metric space with its Borel σ-algebra, and let $f_n : X \to Y$ be measurable maps with $f_n(x) \to g(x)$ for each $x$. Then $g$ is measurable.

*Proof.* It suffices to show that $g^{-1}(U) \in \Sigma_X$ for each open $U \ne Y$. Put $h(y) = d(y, Y \setminus U)$, a continuous function that is positive exactly on $U$, because $Y \setminus U$ is closed. Put $U_k = \{y : h(y) > 1/k\}$, an open set. It is claimed that
$$g^{-1}(U) = \bigcup_{k \ge 1} \bigcup_{N} \bigcap_{n \ge N} f_n^{-1}(U_k).$$
If $g(x) \in U$, choose $k$ with $h(g(x)) > 2/k$. As $h$ is $1$-Lipschitz, $h(f_n(x)) > 1/k$ for all large $n$. Conversely, if $h(f_n(x)) > 1/k$ for all $n \ge N$, then $h(g(x)) = \lim_n h(f_n(x)) \ge 1/k > 0$ by continuity, so $g(x) \in U$. Each $f_n^{-1}(U_k)$ is measurable, so $g^{-1}(U)$ is measurable. $\square$

### Examples

**Example (the Dirichlet function).** Let $f = \mathbf{1}_{\mathbb{Q}} : \mathbb{R} \to \mathbb{R}$. For a Borel set $B$, the preimage $f^{-1}(B)$ is $\emptyset$, $\mathbb{Q}$, $\mathbb{R} \setminus \mathbb{Q}$ or $\mathbb{R}$, according to which of $0$ and $1$ are in $B$. The set $\mathbb{Q}$ is a countable union of closed singletons, so all four sets are Borel, and $f$ is Borel measurable. It is continuous at no point. In Mathlib, see `Measurable.indicator`.

**Counterexample (uncountable suprema).** On $\mathbb{R}$ take the σ-algebra $\Sigma$ of Section 1 of the sets $A$ such that $A$ or $A^c$ is countable. For each $t \in [0, 1]$ the function $\mathbf{1}_{\{t\}} : \mathbb{R} \to \mathbb{R}$ is $\Sigma$-measurable, since its preimages are $\emptyset$, $\{t\}$, $\mathbb{R} \setminus \{t\}$ and $\mathbb{R}$. But $\sup_{t \in [0, 1]} \mathbf{1}_{\{t\}} = \mathbf{1}_{[0, 1]}$, and the preimage of $\{1\}$ is $[0, 1] \notin \Sigma$. So the countability of the index set is necessary in the theorem on suprema. A non-Borel set of Chapter 3 gives the same failure for the Borel sets.

### The library around it

A measurable map with a measurable inverse is a `MeasurableEquiv`, written `α ≃ᵐ β`. A measurable injective map that sends measurable sets to measurable sets is a `MeasurableEmbedding`.

::: mathlib

<?decl MeasurableEquiv?>

Other lemmas: `Measurable.piecewise`, `measurableSet_le`, `measurableSet_lt` and `Monotone.measurable`.

Random graphs need a σ-algebra on graphs. The file `Mathlib.MeasureTheory.Constructions.SimpleGraph` gives `SimpleGraph V` the instance `SimpleGraph.instMeasurableSpace`, the σ-algebra that makes each adjacency $u \sim v$ measurable. The lemma `SimpleGraph.measurable_iff_adj` says that a map $G : \Omega \to$ `SimpleGraph V` is measurable if and only if $\omega \mapsto (G\,\omega).\mathrm{Adj}\, u\, v$ is measurable for all $u$ and $v$. The map to the edge set is measurable, `SimpleGraph.measurable_edgeSet`, and it is a measurable embedding when $V$ is countable, `SimpleGraph.measurableEmbedding_edgeSet`.

Common errors of a learner:

- Writing `Measurable f` for $f : \mathbb{R} \to \mathbb{R}$ and expecting Lebesgue measurability. The instance on `ℝ` is Borel; Lebesgue measurable functions are `AEMeasurable` ones (Chapter 2).
- Taking the supremum over a family whose index type has no `Countable` instance.
- Expecting `Continuous.measurable` with a target that is only `OpensMeasurableSpace`.

### Exercises

1. (A) Show that $f : X \to \mathbb{R}$ is measurable if and only if $\{f \ge a\} \in \Sigma_X$ for each $a \in \mathbb{R}$.
2. (A) Show that each monotone function $f : \mathbb{R} \to \mathbb{R}$ is Borel measurable. Hint: each set $\{f < a\}$ is an interval.
3. (A) Let $f, g : X \to \mathbb{R}$ be measurable. Show that $\{f = g\}$ and $\{f < g\}$ are measurable.
4. (B) Show that $\mathcal{B}(\mathbb{R}^2) = \mathcal{B}(\mathbb{R}) \otimes \mathcal{B}(\mathbb{R})$. Hint: the open rectangles with rational corners are a countable basis and are rectangles.
5. (B) Let $f_n : X \to \mathbb{R}$ be measurable. Show that the set of the points $x$ at which $(f_n(x))$ converges is measurable. Hint: the Cauchy criterion with rational $\varepsilon$.
6. (C) Let $f : X \to \mathbb{R}$ be measurable for $\sigma(g)$, the pull back of $\mathcal{B}(\mathbb{R})$ by a map $g : X \to \mathbb{R}$. Show that $f = h \circ g$ for a Borel function $h$. Hint: first take $f$ an indicator, then a simple function, then a limit.

### Notes and history

Lebesgue's thesis of 1902 defined measurable functions by the condition that the sets $\{a < f < b\}$ are measurable, which is the corollary on real functions. The Mathlib files `MeasurableSpace.Basic` and `MeasurableSpace.Embedding` have the authors Johannes Hölzl and Mario Carneiro, and `BorelSpace.Metrizable` has the author Floris van Doorn.
