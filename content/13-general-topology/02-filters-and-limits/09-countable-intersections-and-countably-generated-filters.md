## Countable intersections and countably generated filters

### Overview

A filter is closed under finite intersections by its definition. Many arguments need the finite form of this rule for a family of sets, and some need more: a filter such as the filter of the sets of full measure is closed under countable intersections. This section describes the part of the library that counts. It starts with the finite rules, then gives the class `CountableInterFilter` and its cardinal form, the filters `Filter.cocountable` and `Filter.cocardinal`, and the countably generated filters.

The countably generated filters are the reason that sequences are enough in a first countable space (Section 3). A filter is countably generated if it has a countable basis, and then it has a decreasing basis indexed by $\mathbb{N}$. The section ends with the kernel of a filter, the intersection of all its sets.

### The library around it

#### Finite families

The module `Mathlib.Order.Filter.Finite` gives the rules for finite families. For a finite set $I$ of indices, $\bigcap_{i \in I} s_i \in f$ if and only if $s_i \in f$ for each $i \in I$ (`Filter.biInter_mem`). The forms for a `Finset`, for a finite type and for a finite set of sets are `Filter.biInter_finset_mem`, `Filter.iInter_mem` and `Filter.sInter_mem`. The same rule for predicates is `Filter.eventually_all`: if $\iota$ is finite, then eventually $p_i(x)$ for all $i$ if and only if for each $i$ eventually $p_i(x)$. Its forms are `Filter.eventually_all_finite` and `Filter.eventually_all_finset`, and the dual rule for `∃ᶠ` is `Filter.frequently_exists`.

The infimum of a family of filters has a finite description. A set $U$ is in $\bigsqcap_i f_i$ if and only if there are a finite set $I$ and sets $V_i \in f_i$ such that $U = \bigcap_{i \in I} V_i$ (`Filter.mem_iInf`). The filter generated by a family $g$ of sets has a similar rule: $U \in \mathrm{generate}(g)$ if and only if some finite $t \subseteq g$ has $\bigcap t \subseteq U$ (`Filter.mem_generate_iff`). The module `Mathlib.Order.Filter.Bases.Finite` gives the bases of these filters: `Filter.hasBasis_generate`, `Filter.hasBasis_iInf_principal_finite` and `Filter.HasBasis.iInf`. It also has `Filter.generate_neBot_iff`, which says that the generated filter is proper if and only if each finite subfamily has a nonempty intersection.

| Lean name | Statement |

The module also gives the eventual equality of finite unions and intersections, such as `Filter.EventuallyEqSet.biInter` and `Filter.EventuallySubset.iUnion`.

#### Filters with countable intersections

The class `CountableInterFilter l` says that $l$ is closed under countable intersections. Its main rule is `countable_sInter_mem`: for a countable family $S$ of sets, $\bigcap S \in l$ if and only if each $s \in S$ is in $l$. The forms for an indexed family are `countable_iInter_mem` and, for predicates, `eventually_countable_forall`. The rule for eventual equality of countable unions is `Filter.EventuallyEqSet.countable_iUnion`.

The class has instances for the principal filters, for $\bot$ and $\top$, for `map` and `comap`, and for $f \sqcap g$ and $f \sqcup g$. The definition `Filter.ofCountableInter` builds a filter from a family of sets that is closed under countable intersections and under supersets. The filter `Filter.countableGenerate g` is the smallest filter with countable intersections that contains $g$: `Filter.countableGenerate_isGreatest` states this property, and `Filter.mem_countableGenerate_iff` says that $s$ is in it if and only if some countable $S \subseteq g$ has $\bigcap S \subseteq s$.

The class `CardinalInterFilter l c` is the generalization to a cardinal $c$: each family of fewer than $c$ sets of $l$ has its intersection in $l$. Each filter satisfies it for $c = \aleph_0$ (`Filter.cardinalInterFilter_aleph0`), and the case $c = \aleph_1$ is the countable case (`cardinalInterFilter_aleph_one_iff`).

#### The cocountable and cocardinal filters

For a regular cardinal $c$, the filter `Filter.cocardinal α hreg` contains the sets whose complement has cardinality less than $c$ (`Filter.mem_cocardinal`). For $c = \aleph_0$ this is the cofinite filter (`Filter.cocardinal_aleph0_eq_cofinite`). For $c = \aleph_1$ it is `Filter.cocountable`, the filter of the sets with a countable complement: $s \in \mathrm{cocountable}$ if and only if $s^c$ is countable (`Filter.mem_cocountable`).

**Proposition.** The filter `Filter.cocountable` has countable intersections.

*Proof sketch.* Let $s_n$ be sets with countable complements. The complement of $\bigcap_n s_n$ is $\bigcup_n s_n^c$, which is a countable union of countable sets, so it is countable. $\square$

The library gets this result from the instance `Filter.instCardinalInterFilter_cocardinal`, which uses the regularity of $c$ in the same way.

#### Separating families

The class `HasCountableSeparatingOn α p t` says that a countable family of sets with the property $p$ separates the points of $t$. The witness is `exists_countable_separating`. The main result is `Filter.exists_singleton_mem_of_forall_separating`. Let $l$ be a filter with countable intersections, and let each set $U$ with property $p$ satisfy $U \in l$ or $U^c \in l$. Then $l$ contains a singleton. For each separating set, take the set $U$ or $U^c$ that is in $l$. The countable intersection of these sets is in $l$, and two of its points are not separated, so it has at most one point. Measure theory uses this result for measures that take only the values 0 and 1.

#### Countably generated filters

The class `Filter.IsCountablyGenerated f` says that $f = \mathrm{generate}(g)$ for a countable family $g$. The structure `Filter.HasCountableBasis` is a basis with a countable index set, and `Filter.HasCountableBasis.isCountablyGenerated` gives the class from it. The class has instances for the principal and point filters, for `map`, `comap`, the infimum and the supremum, and for the product: `Filter.prod.isCountablyGenerated`.

**Theorem.** A filter $f$ is countably generated if and only if it has a decreasing basis indexed by $\mathbb{N}$.

*Proof sketch.* Let $g = \{t_0, t_1, \ldots\}$ generate $f$. Put $s_n = t_0 \cap \cdots \cap t_n$. Then $s_n$ is decreasing, each $s_n$ is in $f$, and each set of $f$ contains a finite intersection of sets of $g$, so it contains some $s_n$. The converse is clear. $\square$

This is `Filter.isCountablyGenerated_iff_exists_antitone_basis`, and `Filter.exists_antitone_basis` gives the basis. The rule `Filter.HasBasis.exists_antitone_subbasis` takes a decreasing basis from a given basis. The decreasing basis is the step that turns a filter argument into a sequence argument: from $x_n \in s_n$ one gets a sequence that tends to $f$. Section 3 uses this step for first countable spaces, and Section 6 uses it for the filter `atTop`.

#### The kernel

The kernel `Filter.ker f` is the intersection of all the sets of $f$ (`Filter.ker_def`, `Filter.mem_ker`). It is a monotone map from filters to sets. It sends `pure a` to $\{a\}$ and $\mathcal{P}(s)$ to $s$ (`Filter.ker_pure`, `Filter.ker_principal`). It commutes with the infimum and the supremum (`Filter.ker_iInf`, `Filter.ker_sup`), with `comap` and with products. The principal filter and the kernel form a Galois coinsertion, `Filter.giPrincipalKer`. The order of filters is reversed with respect to the sets, so $\mathcal{P}(s) \le f$ says that $s$ is a subset of each set of $f$. Thus $\mathcal{P}(s) \le f$ if and only if $s \subseteq \ker f$ (`Filter.subset_ker` is the same rule), and the kernel of $\mathcal{P}(s)$ is $s$. Section 5 uses the kernel of the neighbourhood filter of a set.

#### Common errors

1. The rule `Filter.biInter_mem` needs a finite index set. For an infinite family it is false in general: each set $\{n, n+1, \ldots\}$ is in `atTop`, but their intersection is empty. Use `countable_sInter_mem` only for a filter with the class `CountableInterFilter`.
2. The filter `Filter.cocardinal` takes a proof that the cardinal is regular as an argument. A lemma about `Filter.cocountable` is often stated for the abbreviation, so a goal with `Filter.cocardinal α hreg` can need a rewrite first.
3. A countably generated filter has a basis indexed by $\mathbb{N}$, but a given basis is not countable. Use `Filter.HasBasis.exists_antitone_subbasis` to get a countable subbasis from a given basis.

### Exercises

1. (A) Prove `Filter.eventually_all` for a finite type from `Filter.iInter_mem`.
2. (A) Show that `Filter.cofinite` on $\mathbb{N}$ is not closed under countable intersections.
3. (B) Prove that the cocountable filter on an uncountable type is proper, and that it is not countably generated.
4. (B) Prove that the kernel of the neighbourhood filter of a point $x$ in a $T_1$ space is $\{x\}$.
5. (B) Let $f$ be countably generated with a decreasing basis $s_n$. Show that $u_n \in s_n$ for each $n$ gives a sequence that tends to $f$.
6. (C) Let $l$ be a filter with countable intersections on $\mathbb{R}$ such that each interval $(-\infty, q)$ with $q$ rational is in $l$ or has its complement in $l$. Use `Filter.exists_singleton_mem_of_forall_separating` to show that $l$ contains a singleton.
