# Absolute values and valued fields

An absolute value on a field $F$ makes $F$ a metric space, and so a topological field. The usual absolute value and the $p$-adic absolute values of $\mathbb{Q}$ give different topologies on the same field, and a power $|x|^c$ of an absolute value gives the same topology as $|x|$. This chapter studies which absolute values define the same topology, and the topologies that come from a valuation with values in an ordered group, which need not be a part of $\mathbb{R}$.

Section 1 defines the equivalence of two absolute values as Mathlib does, by the condition that they order the elements of $F$ in the same way. It proves that this condition holds exactly when one absolute value is a positive power of the other, and exactly when the two topologies agree. It then proves the weak approximation theorem: finitely many absolute values that are not equivalent are independent, and $F$ is dense in the product of the fields that they define. Section 2 treats nonarchimedean groups, in which every neighbourhood of $0$ contains an open subgroup, the $I$-adic topology of a ring, and the class `Valued` of Mathlib, which gives a ring the topology of a valuation and a field its completion. Section 3 describes the newer interface of valuative relations, the type `WithVal` and the conditions for a valued field to be locally compact.

The chapter needs Chapters 1 to 3 for topological groups, rings and completions, and Chapter 5, Section 2, for sums in a nonarchimedean group. The theorem of Ostrowski on the absolute values of $\mathbb{Q}$ belongs to number theory, and this chapter cites it only.
