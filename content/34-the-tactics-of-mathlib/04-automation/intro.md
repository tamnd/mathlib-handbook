# Automation

This chapter is about the tactics that search for a proof: `exact?` and `apply?` search the library, `aesop` searches with rules, `fun_prop` and `continuity` prove properties of functions, and `grind` combines several procedures. A search tactic can fail on a true goal, and it can take a long time. Use it to find a proof, and then write the proof that it found into the file.
