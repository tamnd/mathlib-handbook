## Stirling numbers, Bell numbers and derangements

### Overview

This section counts three kinds of structure on a finite set $[n] = \{1, \ldots, n\}$: partitions of the set into blocks, permutations sorted by their number of cycles, and permutations without fixed points. The counts are the Stirling numbers of the second kind, the Stirling numbers of the first kind, the Bell numbers and the derangement numbers. Each one satisfies a recursion that comes from a look at the element $n + 1$: where does it go when it is added to a structure on $[n]$?

Mathlib defines the Stirling numbers, the Bell numbers and the derangement numbers by their recursions. For derangements it also proves that the recursion counts the actual permutations. This section proves the counting statements for all three. It then proves the principle of inclusion and exclusion, uses it for a closed formula for the derangement numbers, and shows that the proportion of derangements among all permutations tends to $1/e$. It ends with the principle of double counting.

### Definitions

**Definition (set partition).** A *partition* of a finite set $A$ is a set of non-empty, pairwise disjoint subsets of $A$, the *blocks*, whose union is $A$. The *Stirling number of the second kind* $S(n, k)$ is the number of partitions of $[n]$ into $k$ blocks. The *Bell number* $B(n)$ is the number of all partitions of $[n]$.

For example, the partitions of $[3]$ are $\{123\}$, $\{1, 23\}$, $\{2, 13\}$, $\{3, 12\}$ and $\{1, 2, 3\}$, with blocks written without braces. So $S(3, 1) = 1$, $S(3, 2) = 3$, $S(3, 3) = 1$ and $B(3) = 5$. The empty set has exactly one partition, the empty set of blocks, so $S(0, 0) = 1$ and $B(0) = 1$. For $n \ge 1$, $S(n, 0) = 0$, and $S(n, k) = 0$ for $k > n$.

A partition of a set is a different object from a partition of an integer in the previous section. The sizes of the blocks of a partition of $[n]$ form a partition of the integer $n$, and many set partitions give the same integer partition.

**Definition (cycles).** Each permutation $\pi$ of a finite set is a product of disjoint cycles, one for each orbit of the group generated by $\pi$, as in Volume 5, Chapter 7. A fixed point is a cycle of length $1$. The *unsigned Stirling number of the first kind* $c(n, k)$ is the number of permutations of $[n]$ with exactly $k$ cycles, fixed points included.

For example, the permutations of $[3]$ are the identity with $3$ cycles, the three transpositions with $2$ cycles each, and the two $3$-cycles. So $c(3, 3) = 1$, $c(3, 2) = 3$ and $c(3, 1) = 2$. Also $c(0, 0) = 1$, because the empty permutation has no cycles.

**Definition (derangement).** A *derangement* of a set $A$ is a permutation of $A$ without fixed points. The number of derangements of $[n]$ is $D(n)$.

For example, the derangements of $[3]$ are the two $3$-cycles, so $D(3) = 2$. The identity of the empty set is a derangement, so $D(0) = 1$, and $D(1) = 0$.

### Theorems and proofs

#### Stirling numbers of the second kind

**Theorem.** For all $n, k \ge 0$,
$$S(n + 1, k + 1) = (k + 1)\, S(n, k + 1) + S(n, k).$$

*Proof.* Sort the partitions of $[n + 1]$ into $k + 1$ blocks by the block of $n + 1$. If $\{n + 1\}$ is a block, remove it. The rest is a partition of $[n]$ into $k$ blocks, and each such partition comes from exactly one partition of this kind. This gives $S(n, k)$ partitions. If the block of $n + 1$ has other elements, remove $n + 1$ from it. The result is a partition of $[n]$ into $k + 1$ blocks, together with the choice of the block that contained $n + 1$. Conversely, a partition of $[n]$ into $k + 1$ blocks and a choice of one of its $k + 1$ blocks give back a unique partition of $[n + 1]$. This gives $(k + 1) S(n, k + 1)$ partitions. $\square$

The recursion, with $S(0, 0) = 1$, $S(0, k + 1) = 0$ and $S(n + 1, 0) = 0$, determines all the values. The first rows are

| $n \backslash k$ | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| 0 | 1 | | | | | |
| 1 | 0 | 1 | | | | |
| 2 | 0 | 1 | 1 | | | |
| 3 | 0 | 1 | 3 | 1 | | |
| 4 | 0 | 1 | 7 | 6 | 1 | |
| 5 | 0 | 1 | 15 | 25 | 10 | 1 |

The row sums $1, 1, 2, 5, 15, 52$ are the Bell numbers, because $B(n) = \sum_k S(n, k)$ by definition.

Write $x^{\underline{j}} = x(x - 1) \cdots (x - j + 1)$ for the falling factorial, with $x^{\underline{0}} = 1$.

**Theorem.** For all natural numbers $x$ and $k$,
$$x^k = \sum_{j = 0}^{k} S(k, j)\, x^{\underline{j}}.$$

*Proof by counting.* The left side counts the maps $f : [k] \to [x]$. Sort them by the partition of $[k]$ into the non-empty fibres of $f$. If this partition has $j$ blocks, the map $f$ is an injective map from the set of $j$ blocks to $[x]$. Once the blocks are listed in a fixed order, there are $x^{\underline{j}}$ such injective maps. So each of the $S(k, j)$ partitions with $j$ blocks contributes $x^{\underline{j}}$ maps. $\square$

*Proof by induction.* For $k = 0$ both sides are $1$. Suppose the identity for $k$. Since $x^{\underline{j+1}} = x^{\underline{j}}(x - j)$, $$x \cdot x^{\underline{j}} = x^{\underline{j + 1}} + j\, x^{\underline{j}}.$$ Multiply the identity for $k$ by $x$ and substitute: $$x^{k+1} = \sum_j S(k, j)\, x^{\underline{j+1}} + \sum_j j\, S(k, j)\, x^{\underline{j}}.$$ The coefficient of $x^{\underline{j+1}}$ is $S(k, j) + (j + 1) S(k, j + 1) = S(k + 1, j + 1)$, and the coefficient of $x^{\underline 0}$ is $0 = S(k + 1, 0)$. $\square$

Both sides are polynomials in $x$ that agree at all natural numbers, so the identity also holds for polynomials.

#### Stirling numbers of the first kind

**Theorem.** For all $n, k \ge 0$,
$$c(n + 1, k + 1) = n\, c(n, k + 1) + c(n, k).$$

*Proof.* Let $\pi$ be a permutation of $[n + 1]$. If $\pi(n + 1) = n + 1$, then $n + 1$ is a cycle of length $1$, and its removal leaves a permutation of $[n]$ with one cycle less. This gives $c(n, k)$ permutations with $k + 1$ cycles. If $\pi(n + 1) \ne n + 1$, remove $n + 1$ from its cycle: define $\pi'$ on $[n]$ by $\pi'(\pi^{-1}(n + 1)) = \pi(n + 1)$ and $\pi'(a) = \pi(a)$ for the other $a$. Then $\pi'$ is a permutation of $[n]$ with the same number of cycles as $\pi$. Conversely, a permutation $\pi'$ of $[n]$ and an element $a \in [n]$ give back $\pi$: insert $n + 1$ into the cycle of $a$ just after $a$, so that $\pi(a) = n + 1$ and $\pi(n + 1) = \pi'(a)$. The two maps are inverse. So this case gives $n\, c(n, k + 1)$ permutations with $k + 1$ cycles. $\square$

The first rows are

| $n \backslash k$ | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | 1 | | | | |
| 2 | 1 | 1 | | | |
| 3 | 2 | 3 | 1 | | |
| 4 | 6 | 11 | 6 | 1 | |
| 5 | 24 | 50 | 35 | 10 | 1 |

Each row sums to $n!$, because each permutation has some number of cycles. The first column is $c(n + 1, 1) = n!$: a single cycle on $[n + 1]$ is a cyclic order, and there are $n!$ cyclic orders. The last but one entry is $c(n + 1, n) = \binom{n+1}{2}$: a permutation of $[n + 1]$ with $n$ cycles is a transposition.

The same argument with a variable gives the generating polynomial of a row. Write $x^{\overline{n}} = x(x + 1) \cdots (x + n - 1)$.

**Theorem.** For all $n \ge 0$, in $\mathbb{Z}[x]$,
$$x^{\overline{n}} = \sum_{k = 0}^{n} c(n, k)\, x^k.$$

*Proof.* Let $P_n = \sum_k c(n, k) x^k$. Then $P_0 = 1$, and the recursion gives $$P_{n+1} = \sum_k \bigl(n\, c(n, k) + c(n, k - 1)\bigr) x^k = (x + n) P_n,$$ where $c(n, -1) = 0$ and the case $k = 0$ uses $c(n + 1, 0) = 0 = n\, c(n, 0)$, which holds for $n = 0$ and for $n \ge 1$. Induction on $n$ gives $P_n = x(x + 1) \cdots (x + n - 1)$. $\square$

#### Bell numbers

**Theorem.** For all $n \ge 0$,
$$B(n + 1) = \sum_{i = 0}^{n} \binom{n}{i} B(n - i).$$

*Proof.* In a partition of $[n + 1]$, the block of $n + 1$ is $\{n + 1\} \cup T$ for a subset $T \subseteq [n]$. Let $i = |T|$. The other blocks form a partition of $[n] \setminus T$, a set with $n - i$ elements. Conversely, a subset $T$ and a partition of its complement give a partition of $[n + 1]$. There are $\binom{n}{i}$ choices of $T$ and $B(n - i)$ partitions of the complement. $\square$

This gives $B(4) = B(3) + 3B(2) + 3B(1) + B(0) = 5 + 6 + 3 + 1 = 15$ and $B(5) = 15 + 4 \cdot 5 + 6 \cdot 2 + 4 \cdot 1 + 1 = 52$.

The partitions of $[n]$ can also be counted by the sizes of their blocks. Let $m$ be a partition of the integer $n$, with $j$ appearing $a_j$ times. Let $B(m)$ be the number of partitions of $[n]$ whose multiset of block sizes is $m$.

**Theorem.** $$B(m) \cdot \prod_{j} (j!)^{a_j} \cdot \prod_{j} a_j! = n!.$$

*Proof.* List the parts of $m$ in decreasing order, $m_1 \ge m_2 \ge \cdots \ge m_r$. A permutation $\sigma$ of $[n]$, written as a word $\sigma(1) \sigma(2) \cdots \sigma(n)$, gives a set partition with block sizes $m$: cut the word into consecutive pieces of lengths $m_1, \ldots, m_r$ and take the sets of letters of the pieces. Each set partition with block sizes $m$ arises in this way. Two words give the same set partition exactly when one comes from the other by a reordering of the letters inside each piece and a reordering of the pieces of equal length. There are $\prod_j (j!)^{a_j}$ reorderings of the first kind and $\prod_j a_j!$ of the second, and together they act freely on the words. So each set partition comes from exactly $\prod_j (j!)^{a_j} \prod_j a_j!$ words. $\square$

For example, the number of ways to split $[6]$ into three pairs is $6!/(2!^3 \cdot 3!) = 15$. Summed over all integer partitions $m$ of $n$, the numbers $B(m)$ give $B(n)$.

#### Derangements

**Theorem.** $D(0) = 1$, $D(1) = 0$, and for all $n \ge 0$,
$$D(n + 2) = (n + 1)\bigl(D(n) + D(n + 1)\bigr).$$

*Proof.* Let $A$ be a set with $n + 1$ elements and let $\ast$ be a new element. Let $\pi$ be a derangement of $A \cup \{\ast\}$ and let $a = \pi(\ast)$. Then $a \in A$, and there are $n + 1$ choices of $a$. Remove $\ast$ from its cycle as in the proof for $c(n, k)$: let $\pi'$ be the permutation of $A$ with $\pi'(\pi^{-1}(\ast)) = a$ and $\pi' = \pi$ elsewhere. The only possible fixed point of $\pi'$ is $a$, and $a$ is fixed exactly when $\pi^{-1}(\ast) = a$, that is, when $\pi$ exchanges $\ast$ and $a$.

- If $\pi'(a) = a$, then $\pi'$ restricted to $A \setminus \{a\}$ is a derangement of a set with $n$ elements.
- If $\pi'(a) \ne a$, then $\pi'$ is a derangement of $A$.

Conversely, for fixed $a$, a derangement of $A \setminus \{a\}$ gives $\pi$ by the transposition of $\ast$ and $a$, and a derangement $\pi'$ of $A$ gives $\pi$ by the insertion of $\ast$ just before $a$ in its cycle. These maps are inverse to the previous ones. So for each $a$ there are $D(n) + D(n + 1)$ derangements $\pi$ with $\pi(\ast) = a$. $\square$

The values are $D(2) = 1$, $D(3) = 2$, $D(4) = 9$, $D(5) = 44$ and $D(6) = 265$. Induction on $n$ also gives the simpler recursion $D(n + 1) = (n + 1) D(n) - (-1)^n$ in $\mathbb{Z}$.

#### Inclusion and exclusion

**Theorem (inclusion and exclusion).** Let $A_1, \ldots, A_r$ be finite sets. Then
$$\Bigl|\bigcup_{i = 1}^{r} A_i\Bigr| = \sum_{\emptyset \ne T \subseteq [r]} (-1)^{|T| + 1} \Bigl|\bigcap_{i \in T} A_i\Bigr|.$$
If the $A_i$ are subsets of a finite set $U$, then the number of elements of $U$ in none of the $A_i$ is
$$\Bigl|\bigcap_{i = 1}^{r} (U \setminus A_i)\Bigr| = \sum_{T \subseteq [r]} (-1)^{|T|} \Bigl|\bigcap_{i \in T} A_i\Bigr|,$$
where the intersection over $T = \emptyset$ is $U$.

*Proof.* Fix an element $x$ of $U$ and count its contribution to each side. Let $I = \{i : x \in A_i\}$. Then $x \in \bigcap_{i \in T} A_i$ exactly when $T \subseteq I$, so the contribution of $x$ to the right side of the second formula is
$$\sum_{T \subseteq I} (-1)^{|T|} = \sum_{j = 0}^{|I|} \binom{|I|}{j} (-1)^j = (1 - 1)^{|I|}.$$
This is $1$ if $I = \emptyset$ and $0$ otherwise, which is the contribution of $x$ to the left side. Sum over $x \in U$. The first formula follows from the second with $U = \bigcup_i A_i$, after the term $T = \emptyset$, which is $|U|$, is moved to the other side. $\square$

The proof is a computation with indicator functions: $1 - \mathbf{1}_{\bigcup A_i} = \prod_i (1 - \mathbf{1}_{A_i})$, and the expansion of the product gives the formula. In this form it holds for sums of any function with values in an abelian group, not only for the count.

**Theorem.** For all $n \ge 0$,
$$D(n) = \sum_{k = 0}^{n} (-1)^k \binom{n}{k} (n - k)! = n! \sum_{k = 0}^{n} \frac{(-1)^k}{k!}.$$

*Proof.* Let $U$ be the set of permutations of $[n]$ and let $A_i$ be the set of permutations that fix $i$. A derangement is a permutation in none of the $A_i$. For $|T| = k$, the permutations that fix each element of $T$ are the permutations of $[n] \setminus T$, so $|\bigcap_{i \in T} A_i| = (n - k)!$. There are $\binom{n}{k}$ such sets $T$. The second formula of inclusion and exclusion gives the first equality, and $\binom{n}{k}(n - k)! = n!/k!$ gives the second. $\square$

**Corollary.** $D(n)/n! \to e^{-1}$ as $n \to \infty$. Also, $D(n)$ is the integer nearest to $n!/e$ for $n \ge 1$.

*Proof.* The sum $\sum_{k \le n} (-1)^k / k!$ is a partial sum of the series of $e^{-1}$ in Volume 15, Chapter 5, so it tends to $e^{-1}$. The tail of this alternating series has terms that decrease in absolute value, so $|e^{-1} - \sum_{k \le n} (-1)^k/k!| < 1/(n + 1)!$. Multiply by $n!$: $|n!/e - D(n)| < 1/(n + 1) \le 1/2$ for $n \ge 1$. $\square$

So a random permutation of a large set has no fixed point with probability close to $1/e \approx 0.368$.

#### Double counting

**Theorem (double counting).** Let $s$ and $t$ be finite sets and let $R \subseteq s \times t$ be a relation. For $a \in s$ let $R(a) = \{b \in t : (a, b) \in R\}$, and for $b \in t$ let $R^{-1}(b) = \{a \in s : (a, b) \in R\}$. Then
$$\sum_{a \in s} |R(a)| = |R| = \sum_{b \in t} |R^{-1}(b)|.$$
If $|R(a)| = m$ for each $a \in s$ and $|R^{-1}(b)| = n$ for each $b \in t$, then $|s| m = |t| n$. If only $|R(a)| \ge m$ and $|R^{-1}(b)| \le n$ hold, then $|s| m \le |t| n$.

*Proof.* Both sums count the pairs in $R$, the first sorted by the first coordinate and the second by the second. The other two statements follow when each term of a sum is replaced by its bound. $\square$

This is the principle behind the handshake lemma of Chapter 1 and the proof of the theorem of Mantel in Chapter 3. Another example: let $s = [n]$ and let $t$ be the set of pairs $(d, q)$ with $dq \le n$. Relate $a$ and $(d, q)$ when $dq = a$. Then $|R(a)|$ is the number $\tau(a)$ of divisors of $a$, and for each $d$ there are $\lfloor n/d \rfloor$ values of $q$, so $\sum_{a \le n} \tau(a) = \sum_{d \le n} \lfloor n/d \rfloor$. This is close to $n \ln n$.

`Finset.sum_card_bipartiteAbove_eq_sum_card_bipartiteBelow` · `Mathlib.Combinatorics.Enumerative.DoubleCounting`

The relation is `r : α → β → Prop`. `s.bipartiteBelow r b` is the finset `{a ∈ s | r a b}` and `t.bipartiteAbove r a` is `{b ∈ t | r a b}`. The theorem says `∑ a ∈ s, #(t.bipartiteAbove r a) = ∑ b ∈ t, #(s.bipartiteBelow r b)`. `Finset.card_mul_le_card_mul` is the inequality `#s * m ≤ #t * n` under the bounds `m ≤ #(t.bipartiteAbove r a)` and `#(s.bipartiteBelow r b) ≤ n`, and `Finset.card_mul_eq_card_mul` is the equality. The versions with a prime exchange the roles of the bounds.

### Examples

**Example (surjections).** The number of surjections from $[k]$ onto $[j]$ is $j!\, S(k, j)$, because a surjection is a partition of $[k]$ into $j$ fibres together with a bijection from the fibres to $[j]$. Inclusion and exclusion over the set of missed values gives the second formula $$j!\, S(k, j) = \sum_{i = 0}^{j} (-1)^i \binom{j}{i} (j - i)^k.$$ For $k = 4$ and $j = 2$: $2^4 - 2 \cdot 1^4 + 0 = 14 = 2!\, S(4, 2)$.

**Example (the hat-check problem).** Ten guests leave their hats, and the hats are returned in a random order. The probability that no guest gets the own hat is $D(10)/10! = 1334961/3628800 \approx 0.367879$. It agrees with $1/e$ to six decimal places.

**Example (the formula of Dobinski, by computation).** The values $B(n)$ for $n \le 5$ agree with $\frac{1}{e}\sum_{j \ge 0} j^n / j!$. For $n = 2$: $\sum_j j^2/j! = \sum_{j \ge 1} j/(j-1)! = \sum_{i \ge 0} (i + 1)/i! = 2e$, so the formula gives $2 = B(2)$. The general proof uses the identity $x^n = \sum_k S(n, k) x^{\underline{k}}$ and $\sum_j j^{\underline k}/j! = e$ for each $k$. The index of this edition has no declaration for this formula.

### The library around it

The enumerative files define the numbers by recursions and prove identities between them, but the bridge from these numbers to the finite structures is in place only for derangements. The index of this edition has no declaration that the Stirling numbers or the Bell numbers count set partitions or cycles. The finite partitions themselves exist as `Finpartition` in `Mathlib.Order.Partition.Finpartition`, and the cycle type of a permutation as `Equiv.Perm.cycleType` in `Mathlib.GroupTheory.Perm.Cycle.Type`. These are the objects that a future bridge would count.

Inclusion and exclusion has a version for measures, `MeasureTheory.measureReal_biUnion_eq_sum_powerset`, and one for integrals, `MeasureTheory.integral_biUnion_eq_sum_powerset`. Double counting has a form for bipartite simple graphs in `Mathlib.Combinatorics.SimpleGraph.Bipartite`.

Common errors of a learner:

- `Nat.stirlingFirst` is the unsigned Stirling number. The signed number $s(n, k) = (-1)^{n-k} c(n, k)$ has no separate definition in the index of this edition.
- `Nat.bell` and `Multiset.bell` are different functions. `Nat.bell n` is the Bell number, and `Multiset.bell m` counts the partitions with block sizes `m`.
- `inclusion_exclusion_card_biUnion` returns an integer. To use it for a natural number count, cast both sides to `ℤ`, for example with `push_cast`.
- `numDerangements_succ` holds in `ℤ`, not in `ℕ`, because of the term $-(-1)^n$.

### Exercises

1. (A) Compute $S(6, 3)$ and $B(6)$ from the recursions.
2. (A) Compute $c(5, k)$ for each $k$ from the rising factorial $x(x + 1)(x + 2)(x + 3)(x + 4)$.
3. (A) List the $9$ derangements of $[4]$, and sort them by the cycle type.
4. (B) Prove $S(n, 2) = 2^{n-1} - 1$ for $n \ge 1$, and $S(n + 1, n) = \binom{n+1}{2}$.
5. (B) Prove $D(n + 1) = (n + 1) D(n) - (-1)^n$ from the recursion of the theorem, and also from the closed formula.
6. (B) Show that the number of permutations of $[n]$ with exactly $j$ fixed points is $\binom{n}{j} D(n - j)$, and deduce $\sum_j \binom{n}{j} D(n - j) = n!$.
7. (B) Use inclusion and exclusion to count the integers in $[1000]$ that are divisible by none of $2$, $3$ and $5$.
8. (B) Prove $c(n, k) \ge S(n, k)$ for all $n$ and $k$. Hint: the cycles of a permutation give a set partition.
9. (C) Prove $\sum_k (-1)^{k} c(n, k) S(k, j) = (-1)^n [n = j]$, where $[n = j]$ is $1$ if $n = j$ and $0$ otherwise. Hint: substitute $x^{\underline{n}} = (-1)^n (-x)^{\overline{n}}$ into the two polynomial identities.
10. (C) Show that $\sum_{n \ge 0} D(n) x^n / n! = e^{-x}/(1 - x)$ as formal power series over $\mathbb{Q}$.

### Notes and history

James Stirling introduced both kinds of numbers in 1730 in the *Methodus differentialis*, as the coefficients that convert between powers and factorial powers. The Bell numbers carry the name of Eric Temple Bell, who wrote about them in the 1930s, but they occur earlier, for example in the work of Ramanujan, and Dobinski gave his formula in 1877. The problem of derangements is the *problème des rencontres* of Pierre Rémond de Montmort (1708), and Nicolaus Bernoulli and Euler solved it. The principle of inclusion and exclusion goes back to de Moivre, and Sylvester stated it in general form. The Authors line of the Mathlib files names Beibei Xiong, Yu Shao, Weijie Jiang and Zhengfeng Yang for the Stirling numbers, Antoine Chambert-Loir and others for the Bell numbers, Henry Swanson for derangements, with Patrick Massot for the limit, and Yaël Dillies for inclusion and exclusion and double counting.
