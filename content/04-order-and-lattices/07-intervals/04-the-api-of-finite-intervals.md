## The API of finite intervals

### Overview

Section 2 defines the finite intervals `Finset.Icc a b`, `Finset.Ico a b` and the others in a locally finite order, and it computes their sizes in $\mathbb{N}$. This section is a guide to the files that make the finite intervals usable in proofs. The largest file, `Mathlib.Order.Interval.Finset.Basic`, repeats for `Finset` most of the rules that Section 1 proves for `Set`: emptiness, inclusion, unions, intersections and differences. It also proves two structural facts about locally finite orders. The order is generated by its covering relation, so a map is monotone when it is monotone on each covering pair. A locally finite order is never dense, except when it has at most one element.

The other files are smaller. They give the intervals as multisets, the cardinalities of the set intervals, the intervals in an order with a successor function, the "boxes" of $\mathbb{Z} \times \mathbb{Z}$, the relation between real intervals and integer intervals by the floor and ceiling functions, and the gaps between disjoint closed subintervals of $[a, b]$. The files use the covering relation and the successor orders of Chapter 1.

### The library around it

**The set rules, again for `Finset`.** Most lemmas of `Mathlib.Order.Interval.Finset.Basic` have the same name and statement as a lemma of Section 1 on `Set`, and their proofs use the coercion: two finsets are equal when their coercions to `Set` are equal, and `Finset.coe_Icc` turns `↑(Finset.Icc a b)` into `Set.Icc a b`. Examples are `Finset.nonempty_Icc`, `Finset.Icc_eq_empty_iff`, `Finset.Icc_subset_Icc`, `Finset.Icc_subset_Icc_iff`, `Finset.Icc_self`, `Finset.Ico_inter_Ico` and `Finset.Ico_sdiff_Ico_left`. In a linear order, two consecutive half-open intervals join.

$$a \le b \le c \implies [a, b) \cup [b, c) = [a, c) \qquad (\texttt{Finset.Ico\_union\_Ico\_eq\_Ico}).$$

The finset version has one property that the set version does not have: its cardinality is a natural number. The lemma `Finset.card_Ico_eq_card_Icc_sub_one` and its variants compare the sizes of the four bounded intervals in a partial order. The lemmas `Finset.Icc_erase_left` and `Finset.Icc_sdiff_both` remove the endpoints. The rays have finset versions only in a `LocallyFiniteOrderTop` or a `LocallyFiniteOrderBot`, for example `Finset.Ici_bot` for the whole of a finite type with a bottom element.

**Bounded sets are finite.** In a locally finite order with a top element structure, each set that is bounded below is finite.

$$\operatorname{BddBelow} s \implies s \text{ finite} \qquad (\texttt{BddBelow.finite}).$$

*Proof.* Let $a$ be a lower bound of $s$. Then $s \subseteq \operatorname{Ici} a$, and in a `LocallyFiniteOrderTop` the ray `Finset.Ici a` is a finset, so its coercion is a finite set. A subset of a finite set is finite. $\square$

The dual `BddAbove.finite` needs `LocallyFiniteOrderBot`. The contrapositive forms `Set.Infinite.exists_gt` and `Set.infinite_iff_exists_gt` say that an infinite subset of $\mathbb{N}$, or of each order with `LocallyFiniteOrderBot`, has elements above each bound.

**The covering relation generates the order.** Let $a \lessdot b$ mean that $a < b$ and no element is strictly between, and let $a \lessdot^{=} b$ be the weak form that allows $a = b$. In a locally finite order, $x \le y$ holds exactly when there is a finite chain $x = z_0 \lessdot^{=} z_1 \lessdot^{=} \dots \lessdot^{=} z_n = y$.

$$x \le y \iff \operatorname{TransGen}(\lessdot^{=})\ x\ y \qquad (\texttt{le\_iff\_transGen\_wcovBy}).$$

The proof is by strong induction on the cardinality of `Finset.Icc x y`. If $x \lessdot^{=} y$, the chain has one step. Otherwise there is $z$ with $x < z < y$, and the intervals $[x, z]$ and $[z, y]$ are strictly smaller than $[x, y]$, so the induction gives chains from $x$ to $z$ and from $z$ to $y$. The strict form is `lt_iff_transGen_covBy`, and in a partial order `le_iff_reflTransGen_covBy` uses the strict covering relation and the reflexive closure. The useful consequence is a test for monotone maps.

$$f \text{ monotone} \iff \forall a\, b,\ a \lessdot b \to f(a) \le f(b) \qquad (\texttt{monotone\_iff\_forall\_covBy}).$$

For $\mathbb{Z}$ or $\mathbb{N}$ the covering pairs are the pairs $(n, n+1)$, so this lemma reduces monotonicity to $f(n) \le f(n+1)$. The variants are `strictMono_iff_forall_covBy`, `antitone_iff_forall_covBy`, `strictAnti_iff_forall_covBy` and `monotone_iff_forall_wcovBy`.

**Locally finite orders are not dense.** A dense order with two elements $a < b$ has infinitely many elements between them, so it cannot be locally finite.

$$\text{dense and locally finite} \implies \neg (a < b) \qquad (\texttt{not\_lt\_of\_denselyOrdered\_of\_locallyFinite}).$$

*Proof.* Suppose $a < b$, and use strong induction on the finset `Finset.Icc a b`. By density there is $c$ with $a < c < b$. Then `Finset.Icc a c` is a strict subset of `Finset.Icc a b`, because $b$ is in the second set and not in the first. The induction hypothesis applied to $a < c$ gives a contradiction. $\square$

The file `Mathlib.Order.Interval.Finset.DenselyOrdered` states the consequence for linear orders: `LocallyFiniteOrder.denselyOrdered_iff_subsingleton` says that a locally finite linear order is dense only if it has at most one element, and `denselyOrdered_set_iff_subsingleton` does the same for a subset with the induced order. The versions `WithBot.denselyOrdered_set_iff_subsingleton` and `WithTop.denselyOrdered_set_iff_subsingleton` treat a subset of `WithBot X` and `WithTop X`.

**Successor orders.** In a linear order with a successor function `Order.succ`, the half-open and closed intervals convert into each other. The file `Mathlib.Order.Interval.Finset.SuccPred` has these rules for finsets, and `Mathlib.Order.Interval.Set.SuccPred` has the same rules for sets.

$$[a, \operatorname{succ} b) = [a, b] \qquad (\texttt{Finset.Ico\_succ\_right\_eq\_Icc}).$$

This form needs `NoMaxOrder`, because at a maximal element $b$ the successor is $b$ itself and the left side loses $b$. The general form is `Finset.Ico_succ_right_eq_Icc_of_not_isMax`, with the hypothesis `¬IsMax b`. The other lemmas follow the same pattern: `Finset.Ico_succ_left_eq_Ioo` needs no hypothesis, `Finset.Iio_succ_eq_Iic` changes a ray, and `Finset.insert_Icc_right_eq_Icc_succ` adds one point at the right end. The predecessor versions replace `succ` by `pred` and `IsMax` by `IsMin`. For $\mathbb{N}$ and $\mathbb{Z}$, the ring files have the same lemmas with $n + 1$ and $n - 1$ in place of `succ` and `pred`.

**Cardinalities of set intervals.** The file `Mathlib.Order.Interval.Set.Card` computes the size of a set interval from the size of the finset interval, in three forms: `Set.ncard_Icc` with a natural number, `Set.encard_Icc` with a value in $\mathbb{N}_\infty$, and `Set.cardinalMk_Icc` with a cardinal.

$$\#\,\operatorname{Set.Icc} a\, b = \#\,\operatorname{Finset.Icc} a\, b \qquad (\texttt{Set.ncard\_Icc}).$$

The file `Mathlib.Order.Interval.Set.Nat` combines these with the formulas of Section 2: `Set.ncard_Icc_nat` says that $[a, b] \subseteq \mathbb{N}$ has $b + 1 - a$ elements, and `Set.ncard_Ico_nat`, `Set.ncard_Ioo_nat` and `Set.ncard_Iic_nat` give the other cases. The subtraction is truncated, so the formulas are correct also when $b < a$.

**Multisets.** The file `Mathlib.Order.Interval.Multiset` defines `Multiset.Icc a b` and the seven other intervals as the underlying multiset of the finset interval. Its lemmas repeat the finset lemmas with $0$ for the empty multiset, for example `Multiset.Icc_eq_zero_iff`, and `Multiset.nodup_Icc` says that the multiset has no repeated element. The file `Mathlib.Order.Interval.Finset.Nat` uses the multiset form when an interval of $\mathbb{N}$ is mapped by a function that is not injective: the image of `Multiset.Ico n (n + a)` under $x \mapsto x \bmod a$ is `Multiset.range a`, and the multiset keeps the multiplicities that a finset would lose.

**Floor and ceiling.** For a ring with a floor function, such as $\mathbb{R}$ or $\mathbb{Q}$, the file `Mathlib.Order.Interval.Finset.Floor` turns a question about integers in a real interval into a question about an integer interval.

$$(n : \alpha) \in [a, b] \iff n \in [\lceil a \rceil, \lfloor b \rfloor] \qquad (\texttt{Int.cast\_mem\_Icc\_iff}).$$

The right side is a finset of $\mathbb{Z}$, so its size is $\lfloor b \rfloor + 1 - \lceil a \rceil$ by the formulas of Section 2. The open ends use the other function: `Int.cast_mem_Ioo_iff` has $\lfloor a \rfloor$ and $\lceil b \rceil$. The `Nat` versions, such as `Nat.cast_mem_Icc_iff`, use `⌊b⌋₊` and `⌈a⌉₊` and need a hypothesis of nonnegativity in some cases.

**Boxes.** In a locally finite ordered ring α, the file `Mathlib.Order.Interval.Finset.Box` defines `Finset.box n` as the "hollow box" `Finset.Icc (-n) n` minus `Finset.Icc (-(n-1)) (n-1)`, with `Finset.box 0 = {0}`. The boxes are disjoint and their union is α. For $\mathbb{Z} \times \mathbb{Z}$, `Int.mem_box` says that $x \in \operatorname{box} n$ when $\max(|x_1|, |x_2|) = n$, with `Int.natAbs` for the absolute value, and the size of a box is computed.

$$n \ne 0 \implies \#\operatorname{box}(n) = 8n \text{ in } \mathbb{Z} \times \mathbb{Z} \qquad (\texttt{Int.card\_box}).$$

The square $[-n, n]^2$ has $(2n+1)^2$ points and the square $[-(n-1), n-1]^2$ has $(2n-1)^2$, and the difference is $8n$. The lemma `Int.existsUnique_mem_box` says that each point is in exactly one box. The boxes are used in the file on the summability of Eisenstein series, where a sum over $\mathbb{Z}^2$ is split into a sum over boxes.

**Gaps between subintervals.** Let $F$ be a finite set of pairs $(x, y)$ with $a \le x \le y \le b$, such that the intervals $[x, y]$ are pairwise disjoint. The file `Mathlib.Order.Interval.Finset.Gaps` defines `Finset.intervalGapsWithin`, which lists the $k + 1$ gaps between them from left to right, where $k$ is the number of pairs: the first gap starts at $a$, the last gap ends at $b$, and each other gap goes from the right end of one interval to the left end of the next. The lemma `Finset.intervalGapsWithin_pairwiseDisjoint_Ioc` says that the half-open gaps $(\text{start}, \text{end}]$ are pairwise disjoint, and `Finset.intervalGapsWithin_mapsTo`, `Finset.intervalGapsWithin_injOn` and `Finset.intervalGapsWithin_surjOn` say that the ends of consecutive gaps recover $F$. The file `Mathlib.Algebra.BigOperators.Group.Finset.Gaps` uses the gaps to split a sum over $[a, b]$.

#### Common errors

1. Using the `NoMaxOrder` form of a successor lemma in an order with a top element. In `Fin (n + 1)` the last element is maximal, so `Finset.Ico_succ_right_eq_Icc` does not apply. Use `Finset.Ico_succ_right_eq_Icc_of_not_isMax` with a proof of `¬IsMax b`.
2. Confusing `Set.ncard` and `Finset.card`. A goal about the number of elements of `Set.Icc a b` needs `Set.ncard_Icc` first, to move to `Finset.Icc a b`; the lemmas of Section 2 such as `Nat.card_Icc` are stated for the finset.
3. Expecting `BddBelow.finite` in an order without `LocallyFiniteOrderTop`. In $\mathbb{Z}$ the instance exists only as `LocallyFiniteOrder`, and a set bounded below can be infinite. Use `BddBelow.finite_of_bddAbove` with bounds on both sides.

### Exercises

1. (A) Use `Int.cast_mem_Icc_iff` to show that the real interval $[\tfrac{1}{2}, \tfrac{7}{2}]$ contains exactly three integers.
2. (A) Prove with `monotone_iff_forall_covBy` that a map $f : \mathbb{Z} \to \mathbb{Z}$ with $f(n) \le f(n+1)$ for each $n$ is monotone.
3. (B) Prove that $\mathbb{Q}$ has no `LocallyFiniteOrder` instance, with `not_lt_of_denselyOrdered_of_locallyFinite`.
4. (B) Show that $[0, 3) \cup [3, 7) = [0, 7)$ as finsets of $\mathbb{N}$, and compute the cardinality of each part with `Nat.card_Ico`.
5. (B) Prove `Set.ncard_Ioo_nat` from `Set.ncard_Ioo` and the formula for `Nat.card_Ioo`.
6. (C) Prove `Int.card_box` by hand for $n = 1$ and $n = 2$ by listing the points, and explain why the formula fails for $n = 0$.
