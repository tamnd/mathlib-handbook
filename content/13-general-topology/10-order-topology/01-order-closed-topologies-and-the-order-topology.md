## Order-closed topologies and the order topology

### Overview

A type can carry an order and a topology that do not know each other. The library connects them with a short list of classes. The weakest classes say that the rays $(-\infty, a]$ or $[a, \infty)$ are closed. The class of order-closed topologies says that the graph of $\le$ is closed in $X \times X$. The strongest class says that the topology is the order topology, the topology generated by the open rays. The real line, the extended reals, each complete linear order with its usual topology and each finite product of such spaces satisfy the classes that apply to them.

This section describes the basic API of these classes. It covers the closedness of inequalities, limits of inequalities, the neighbourhood filters of the order topology, the squeeze theorem, and the facts that each linear order topology is Hausdorff, completely normal and has a basis of order-connected open sets. The last modules treat the order completion of a linear order, the bornology of bounded sets, and countable families of rays that separate points.

The text uses filters and neighbourhoods from Chapter 2 and the separation axioms from Chapter 4. Section 2 of Chapter 1 already defines the class `OrderTopology` as an example of a generated topology.

### The library around it

#### The classes

The module `Mathlib.Topology.Order.OrderClosed` defines three classes for a preorder with a topology. `ClosedIicTopology α` says that each set `Set.Iic a` is closed, and `ClosedIciTopology α` says the same for `Set.Ici a`. `OrderClosedTopology α` says that the set $\{(x, y) : x \le y\}$ is closed in the product. This set is the content of `isClosed_le_prod`. An order-closed topology has both closed-ray classes, and for a linear order it is Hausdorff by `OrderClosedTopology.to_t2Space`. The proof is short: if $x < y$, then $\{(a, b) : b < a\}$ is an open set that contains $(y, x)$, and a product neighbourhood of $(x, y)$ inside the complement of the diagonal gives disjoint neighbourhoods.

The module `Mathlib.Topology.Order.Basic` treats the order topology. The topology `Preorder.topology α` is generated by the open rays `Set.Ioi a` and `Set.Iio a`. The class `OrderTopology α` says that the topology of the instance equals this topology; its field is `OrderTopology.topology_eq_generate_intervals`, and `isOpen_iff_generate_intervals` unfolds it. For a linear order the order topology is order-closed, by `OrderTopology.to_orderClosedTopology`. The converse is false: the discrete topology on $\mathbb{R}$ is order-closed and is not the order topology.

Many lemmas of the volume ask only for the weakest class that they need. The rule is: a lemma about upper bounds or limits from below asks for `ClosedIicTopology`, the lemma for lower bounds asks for `ClosedIciTopology`, and a lemma about two functions asks for `OrderClosedTopology`. The order topology is necessary only when a lemma builds open sets from intervals.

#### Inequalities are closed

The main result of the module is the closedness of inequalities. Let $f, g : \beta \to \alpha$ be continuous, with $\alpha$ order-closed. Then

$$\{b : f(b) \le g(b)\} \text{ is closed.}$$

This is `isClosed_le`. *Proof.* The set is the preimage of the closed set $\{(x, y) : x \le y\}$ under the continuous map $b \mapsto (f(b), g(b))$. For a linear order the complement of this set is $\{b : g(b) < f(b)\}$, so `isOpen_lt` follows. Other forms are `IsClosed.isClosed_le` for maps continuous on a closed set, `closure_lt_subset_le`, `IsClosed.epigraph` and `IsClosed.hypograph`, and the closedness of the set of monotone maps, `isClosed_monotone`.

The form for filters is the usual way to pass an inequality to the limit. If $f \to a_1$ and $g \to a_2$ along a proper filter, and $f \le g$ eventually, then $a_1 \le a_2$. This is `le_of_tendsto_of_tendsto`. The forms with a constant are `le_of_tendsto` and `ge_of_tendsto`, and they need only a closed-ray class. The proof of the main form uses `isClosed_le_prod`: the pair $(f, g)$ tends to $(a_1, a_2)$, it is eventually in the closed set $\{x \le y\}$, and a closed set contains each limit of a filter that is eventually in it.

The same closedness gives the simple facts on intervals. The closed intervals are closed (`isClosed_Icc`, `isClosed_Ici`, `isClosed_Iic`), and the open ones are open in a linear order (`isOpen_Ioo`, `isOpen_Ioi`, `isOpen_Iio`). The closure of a closed interval is itself (`closure_Icc`), and the interior of an open one is itself (`interior_Ioo`). A closed interval is a neighbourhood of each point strictly inside it (`Icc_mem_nhds`), and its one-sided forms are `Icc_mem_nhdsGE` and `Ioo_mem_nhdsGT`. The module `Mathlib.Topology.Order.IsLocallyClosed` adds that each interval is locally closed, for example `isLocallyClosed_Ioo` and `isLocallyClosed_Ici`.

The eventual forms are as frequent as the closed sets. If $a < b$, then eventually $x < b$ near $a$ (`eventually_lt_nhds`). If $f \to v$ and $u < v$, then eventually $u < f$ (`Filter.Tendsto.eventually_const_lt`). The maps $\min$ and $\max$ are continuous (`continuous_min`, `continuous_max`), with the dot forms `Continuous.min` and `Filter.Tendsto.max`. Bounds pass to the closure: `upperBounds_closure` and `bddAbove_closure`. A dense set meets each nonempty open interval of a densely ordered space (`Dense.exists_between`). Near the point at infinity, a neighbourhood filter and `Filter.atTop` are disjoint when the order has no top (`disjoint_nhds_atTop`).

The names of the lemmas on one-sided neighbourhood filters use the fragments nhdsGE, nhdsGT, nhdsLE and nhdsLT. For example, `nhdsWithin_Ioo_eq_nhdsLT` states that the filter of $b$ within $(a, b)$ is the filter within $(-\infty, b)$. The lemmas `continuousWithinAt_Ioo_iff_Iio` and its siblings make the same change for continuity. In a successor order the filter from the right is trivial (`SuccOrder.nhdsGT`), and an order-closed topology on an order with both successors and predecessors is discrete (`DiscreteTopology.of_predOrder_succOrder`).

#### The neighbourhoods of the order topology

In the order topology the neighbourhood filter of $a$ has an explicit form:

$$\mathcal{N}(a) = \bigsqcap_{b < a} \mathcal{P}((b, \infty)) \sqcap \bigsqcap_{b > a} \mathcal{P}((-\infty, b)).$$

This is `nhds_eq_order`. Its consequence `tendsto_order` is the form a reader uses: $f \to a$ if and only if for each $a' < a$, eventually $a' < f$, and for each $a' > a$, eventually $f < a'$. *Proof of the squeeze theorem.* Let $g \to a$, $h \to a$ and $g \le f \le h$. For $a' < a$, eventually $a' < g \le f$, and for $a' > a$, eventually $f \le h < a'$. Then `tendsto_order` gives $f \to a$. This is `Filter.Tendsto.squeeze`, with the long name `tendsto_of_tendsto_of_tendsto_of_le_of_le` and a primed form for eventual inequalities.

The bases of the neighbourhood filters follow. With no maximum and no minimum, the open intervals around $a$ are a basis (`nhds_basis_Ioo`, `mem_nhds_iff_exists_Ioo_subset`). The one-sided forms are `nhdsGE_basis` and `nhdsLE_basis`, and the forms at a top or bottom element are `nhds_top_basis` and `nhds_bot_basis`. For a finite product of order topologies, a box of open intervals is a neighbourhood (`pi_Ioo_mem_nhds`). The instances such as `tendstoIccClassNhds` tell the filter library that small intervals around a point stay near it.

Two points of a linear order are separated by open sets that are ordered: if $a_1 < a_2$, there are open sets $U \ni a_1$ and $V \ni a_2$ with $u < v$ for all $u \in U$ and $v \in V$. This is `order_separated`. *Proof.* If some $c$ lies strictly between $a_1$ and $a_2$, take $U = (-\infty, c)$ and $V = (c, \infty)$. If there is no such $c$, take $U = (-\infty, a_2)$ and $V = (a_1, \infty)$.

The module also treats the order topology of a subset and the image of a map. A strictly monotone map with an order-connected range is an embedding (`StrictMono.isEmbedding_of_ordConnected`). An order-connected subset has the order topology (`orderTopology_of_ordConnected`), and `induced_orderTopology` gives the order topology on the source of a map that reflects $<$ and has a dense image. A dense subset generates the topology with its own rays (`Dense.topology_eq_generateFrom`). Countability results close the module. In a second countable order topology the set of points with an immediate successor is countable (`countable_setOfPred_covBy_right`). A family of disjoint nonempty open intervals is countable (`Set.PairwiseDisjoint.countable_of_Ioo`). A separable densely ordered space is second countable (`SecondCountableTopology.of_separableSpace_orderTopology`).

#### Neighbourhoods of intervals and limits at the ends

The module `Mathlib.Topology.Order.NhdsSet` computes the neighbourhood filter of an interval. For $a \le b$ the filter of $[a, b]$ is the join of the filters of the two ends and the principal filter of $(a, b)$:

$$\mathcal{N}([a, b]) = \mathcal{N}(a) \sqcup \mathcal{N}(b) \sqcup \mathcal{P}((a, b)).$$

This is `nhdsSet_Icc`, and the module has one such lemma for each kind of interval. The membership lemmas have names such as `Ioi_mem_nhdsSet_Ici_iff`, which says that $(a, \infty)$ is a neighbourhood of $[b, \infty)$ if and only if $a < b$. The basis `hasBasis_nhdsSet_Iic_Iio` gives the open rays as a basis of the neighbourhoods of a closed ray.

The module `Mathlib.Topology.Order.AtTopBotIxx` compares two ways to go to the end of an interval. On the subtype $(a, b)$, the filter `Filter.atTop` is the image of the filter of $b$ from the left, when $b$ has no immediate predecessor. This is `map_coe_Ioo_atTop`, and `tendsto_Ioo_atTop` is its form for limits. The module `Mathlib.Topology.Order.Filter` treats the space of filters with its own topology: the map `nhds` tends to `Filter.atTop` along `Filter.atTop` (`Filter.tendsto_nhds_atTop`).

#### Normality, bases and separation by rays

Each linear order with the order topology is completely normal, so it is $T_5$. These are `OrderTopology.completelyNormalSpace` and `OrderTopology.t5Space` in the module `Mathlib.Topology.Order.T5`. The proof builds the separating neighbourhoods from the order. For two separated sets $s$ and $t$, the set `Set.ordT5Nhd` cuts out an order-connected piece around each point of $s$ that avoids $t$, and `Set.ordT5Nhd_mem_nhdsSet` says that the result is a neighbourhood of $s$.

The module `Mathlib.Topology.Order.Separable` says that the open order-connected sets are a basis (`isTopologicalBasis_isOpen_ordConnected`). It follows that each subset of a separable linear order is separable (`Set.separableSpace`), and that the isolated points of a subset are countable (`countable_ofPred_isolated_within`). The module `Mathlib.Topology.Order.CountableSeparating` gives the countable families of rays that separate the points of a second countable order. The consequence `Filter.EventuallyEq.of_forall_eventually_le_iff` says: along a filter that is closed under countable intersections, two maps are eventually equal if for each $x$ the events $f \le x$ and $g \le x$ are eventually the same.

#### Completions and bornology

The module `Mathlib.Topology.Order.Completion` puts the order topology on the order completion. The type `Order.Fill α` is a subtype of $\alpha \times \mathbb{Q}$ with the lexicographic order. The order embedding `Order.Fill.some` sends $a$ to $(a, 0)$. The type is densely ordered and has the order topology (`Order.Fill.instOrderTopology`). The embedding is continuous (`Order.Fill.continuous_some`), and so is the embedding of a linear order into its Dedekind cuts (`DedekindCut.continuous_principal`). The theorem `Order.exists_dense_continuous_completion` collects these facts: each linear order with the order topology embeds continuously into a dense and complete linear order. The proof takes the Dedekind completion of `Order.Fill α`.

The module `Mathlib.Topology.Order.Bornology` relates a bornology to an order. The class `IsOrderBornology α` says that a set is bounded if and only if it is bounded below and above, by `isBounded_iff_bddBelow_bddAbove`. For a lattice, the bornology `orderBornology` has this property. With no maximum and no minimum the filter of cobounded sets is `Filter.atBot ⊔ Filter.atTop` (`IsOrderBornology.cobounded_eq`). The class is stable under products and order duals.

#### Common errors

1. A lemma such as `le_of_tendsto` asks for `ClosedIicTopology`, not for `OrderTopology`. A proof that adds the stronger class to a statement makes the lemma harder to use. State a result with the weakest class that the proof needs.
2. The basis `nhds_basis_Ioo` needs `NoMaxOrder` and `NoMinOrder`. At a top element, such as $\top$ in `EReal`, use `nhds_top_basis` instead.
3. The names of the lemmas on one-sided filters use the fragments nhdsGE, nhdsGT, nhdsLE and nhdsLT for the filters such as `nhdsWithin a (Set.Ici a)`. A search for the long form of the filter in a name does not find them.

### Exercises

1. (A) Use `isClosed_le` to prove that the set $\{x \in \mathbb{R} : \sin x \le \cos x\}$ is closed.
2. (A) Let $u_n \to a$ and $u_n \le b$ for all $n$ in a space with `ClosedIicTopology`. Prove $a \le b$ with `le_of_tendsto'`, and say why the filter must be proper.
3. (B) Prove that a linear order with an order-closed topology is Hausdorff. Use `isOpen_lt` on the product.
4. (B) Prove `tendsto_order` from `nhds_eq_order`, and then prove the squeeze theorem from `tendsto_order`.
5. (B) Show that the discrete topology on $\mathbb{Z}$ is the order topology, and that the discrete topology on $\mathbb{Q}$ is order-closed but is not the order topology.
6. (C) Prove that in a second countable linear order with the order topology the set of points $x$ with an immediate successor is countable. Hint: for each such $x$ the set `Set.Iic x` is open.
