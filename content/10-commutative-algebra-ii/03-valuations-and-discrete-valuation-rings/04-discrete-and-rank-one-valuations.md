## Discrete valuations and valuations of rank one

### Overview

Section 1 allows a valuation to take values in any linearly ordered group with zero. Two special kinds appear in number theory and geometry. A valuation is discrete when its nonzero values form an infinite cyclic group, so that it is a power of the $p$-adic valuation in disguise. A valuation has rank one when its value group embeds into the positive real numbers, so that it gives an absolute value and a metric. A discrete valuation has rank one.

This section describes the classes for the two kinds, uniformizers, the link with the discrete valuation rings of Section 3, and the criteria by the archimedean property. It ends with the additive valuation that the multiplicity of a prime element defines.

### The library around it

#### Discrete valuations

Let $\Gamma$ be a linearly ordered commutative group with zero and $v : A \to \Gamma$ a valuation. The value group `MonoidWithZeroHom.valueGroup v` is the subgroup of $\Gamma^\times$ generated by the nonzero values. The class `Valuation.IsRankOneDiscrete v` in `Mathlib.RingTheory.Valuation.Discrete.Basic` asks for $\gamma < 1$ with $\langle \gamma \rangle$ equal to the value group. Its field is `Valuation.IsRankOneDiscrete.exists_generator_lt_one`. The chosen generator is `Valuation.IsRankOneDiscrete.generator v`, with `Valuation.IsRankOneDiscrete.generator_lt_one` and `Valuation.IsRankOneDiscrete.generator_zpowers_eq_valueGroup`. It is the generator below $1$ of a cyclic group, `LinearOrderedCommGroup.Subgroup.genLTOne`. The class implies that $v$ is nontrivial, by `Valuation.IsRankOneDiscrete.instIsNontrivial`, and it is invariant under equivalence of valuations, `Valuation.IsEquiv.isRankOneDiscrete_iff`.

For $\Gamma = \mathbb{Z}^{m0}$, the usual target of discrete valuations, the generator is $\exp(-1)$ when $v$ is surjective: `Valuation.IsRankOneDiscrete.generator_eq_exp_neg_one_of_surjective`.

#### Uniformizers

An element $\pi$ is a uniformizer, `v.IsUniformizer π`, if $v(\pi)$ is the generator. The structure `Valuation.Uniformizer v` bundles an element of the ring of integers with this property.

| Lean name | Statement |
|---|---|
| `Valuation.IsUniformizer.iff` | $\pi$ is a uniformizer if and only if $v(\pi) = \gamma$ |
| `Valuation.IsUniformizer.val_lt_one` | $v(\pi) < 1$ |
| `Valuation.IsUniformizer.ne_zero` | $\pi \ne 0$ |
| `Valuation.IsUniformizer.not_isUnit` | a uniformizer is not a unit of the integers |
| `Valuation.IsUniformizer.zpowers_eq_valueGroup` | $v(\pi)$ generates the value group |
| `Valuation.exists_isUniformizer_of_isCyclic_of_nontrivial` | a uniformizer exists on a field |
| `Valuation.associated_of_isUniformizer` | two uniformizers are associated |
| `Valuation.IsUniformizer.of_associated` | an associate of a uniformizer is a uniformizer |

**Theorem.** Let $K$ be a field with a discrete valuation $v$, $\mathcal{O}$ its valuation ring and $\pi$ a uniformizer. Then $\mathfrak m = (\pi)$, and each nonzero $r \in \mathcal{O}$ is $r = \pi^n u$ with $u$ a unit. These are `Valuation.Uniformizer.is_generator` and `Valuation.exists_pow_Uniformizer`.

*Proof.* Let $r \in \mathcal{O}$ be nonzero. Then $v(r) = \gamma^n$ for some $n \in \mathbb{Z}$, and $n \ge 0$ since $v(r) \le 1$. Put $u = r\pi^{-n}$. Then $v(u) = 1$, so $u$ and $u^{-1}$ lie in $\mathcal{O}$ and $u$ is a unit. If $r \in \mathfrak m$, then $v(r) < 1$ and $n \ge 1$, so $r \in (\pi)$. $\square$

It follows that every ideal of $\mathcal{O}$ is principal, `Valuation.ideal_isPrincipal`, that $\mathfrak m^n = (\pi^n)$, `Valuation.pow_Uniformizer_is_pow_generator`, and that $\mathcal{O}$ is a discrete valuation ring: the instance `Valuation.valuationSubring_isDiscreteValuationRing`. It is not a field, `Valuation.valuationSubring_not_isField`. Conversely, a generator of the maximal ideal is a uniformizer, `Valuation.isUniformizer_of_maximalIdeal_eq_span`.

#### Discrete valuation rings

The module `Mathlib.RingTheory.Valuation.Discrete.IsDiscreteValuationRing` goes the other way. A discrete valuation ring $A$ with fraction field $K$ has one height one prime, `IsDiscreteValuationRing.maximalIdeal A`, and its adic valuation on $K$ is discrete: the instance `IsDiscreteValuationRing.isRankOneDiscrete`. The ring $A$ is its valuation ring, by `IsDiscreteValuationRing.equivValuationSubring` and `IsDiscreteValuationRing.exists_lift_of_le_one`, and two elements with the same value are associated, `IsDiscreteValuationRing.associated_of_valuation_eq`. For a valuation subring $A$ of a field that is a discrete valuation ring, the instance `ValuationSubring.isRankOneDiscrete_valuation` makes its valuation discrete.

#### Rank one valuations

The class `Valuation.RankOne v` in `Mathlib.RingTheory.Valuation.RankOne` gives a strictly monotone map of monoids with zero `Valuation.RankOne.hom v` from the value group with zero to $\mathbb{R}_{\ge 0}$, and asks that $v$ is nontrivial. The weaker class `Valuation.RankLeOne v` drops nontriviality. With a rank one valuation, $x \mapsto$ `RankOne.hom v (v x)` is a real absolute value, and this is how a valued field becomes a normed field in Volume 14.

| Lean name | Statement |
|---|---|
| `Valuation.RankOne.strictMono` | the map to $\mathbb{R}_{\ge 0}$ is strictly monotone |
| `Valuation.RankOne.hom_eq_zero_iff` | it vanishes only at $0$ |
| `Valuation.RankOne.nontrivial` | some $r$ has $v(r) \ne 0, 1$ |
| `Valuation.RankOne.exists_val_lt` | on a field, values become arbitrarily small |
| `Valuation.RankLeOne.rankOne_of_exists` | rank at most one and nontrivial gives rank one |
| `Valuation.IsRankOneDiscrete.rankOne` | a discrete valuation has rank one, for a base $e > 1$ |

**Theorem.** Let $v$ be nontrivial. Then $v$ has rank one if and only if its value group with zero is archimedean. This is `Valuation.nonempty_rankOne_iff_mulArchimedean`.

*Proof sketch.* A subgroup of $\mathbb{R}_{>0}$ is archimedean, so a strictly monotone embedding forces the value group to be archimedean. The converse is Hölder's theorem: an archimedean linearly ordered group embeds into $\mathbb{R}$ as an ordered group. $\square$

The module `Mathlib.RingTheory.Valuation.Discrete.RankOne` makes the rank one structure of a discrete valuation concrete. The isomorphism `Valuation.IsRankOneDiscrete.valueGroup₀_equiv_withZeroMulInt` identifies the value group with zero of a discrete valuation with $\mathbb{Z}^{m0}$, and sends the generator to $\exp(-1)$, by `Valuation.IsRankOneDiscrete.valueGroup₀_equiv_withZeroMulInt_apply_zpow`. The definition `Valuation.IsRankOneDiscrete.rankOne` then sends $\exp(-k)$ to $e^{-k}$ for a chosen real $e > 1$.

The same notions exist for valuative relations, described in the next section. The results `ValuativeRel.isRankLeOne_iff_mulArchimedean` and `ValuativeRel.isNontrivial_of_rankOne` are the relation forms. In `Mathlib.RingTheory.Valuation.DiscreteValuativeRel`, `ValuativeRel.ValueGroupWithZero.nonempty_orderMonoidIso_withZeroMulInt_iff` says that the value group with zero of a relation is isomorphic to $\mathbb{Z}^{m0}$ if and only if the relation is discrete, nontrivial and archimedean.

#### Archimedean value groups and principal ideals

Let $v$ be a valuation on a field $F$ with ring of integers $\mathcal{O}$. The module `Mathlib.RingTheory.Valuation.Archimedean` relates the shape of the value group to the ideals of $\mathcal{O}$.

1. `Valuation.Integers.isPrincipalIdealRing_iff_not_denselyOrdered` says that $\mathcal{O}$ is a principal ideal ring if and only if the set of values is not densely ordered.
2. `Valuation.Integers.wfDvdMonoid_iff_wellFounded_gt_on_v` says that divisibility in $\mathcal{O}$ is well founded if and only if the order $>$ on the values of $\mathcal{O}$ is well founded.
3. `Valuation.Integers.wellFounded_gt_on_v_iff_discrete_mrange` says that this happens if and only if the range of $v$ is isomorphic to $\mathbb{Z}^{m0}$.

For example, a valuation with values in $\mathbb{Q}_{>0}$ and all of them attained has a densely ordered value set, and its ring of integers has a maximal ideal that is not finitely generated.

#### The multiplicity of a prime

Let $R$ be a domain and $p$ a prime element. The module `Mathlib.RingTheory.Valuation.PrimeMultiplicity` defines `multiplicity_addValuation hp`, the additive valuation $r \mapsto \operatorname{ord}_p(r)$ with values in $\mathbb{N}_\infty$. By `multiplicity_addValuation_apply` it is `emultiplicity p r`, the largest $n$ with $p^n \mid r$, and $\infty$ at $r = 0$. The valuation axioms are the identities $\operatorname{ord}_p(rs) = \operatorname{ord}_p(r) + \operatorname{ord}_p(s)$, which needs $p$ prime, and $\operatorname{ord}_p(r + s) \ge \min$.

#### Common errors

1. `Valuation.IsUniformizer` needs an instance of `Valuation.IsRankOneDiscrete v`, since its definition uses the chosen generator.
2. The value group of `Valuation.IsRankOneDiscrete` is the group generated by the values, not $\Gamma^\times$. A valuation into $\mathbb{R}_{\ge 0}$ can be discrete.
3. `Valuation.RankOne v` is a class with data, the map to $\mathbb{R}_{\ge 0}$. Two instances can differ by a power, so lemmas about the absolute value depend on the instance.

### Exercises

1. (A) Show that the $p$-adic valuation of $\mathbb{Q}$ is discrete, and that $p$ is a uniformizer.
2. (A) Let $v$ be discrete with uniformizer $\pi$. Show that $u\pi$ is a uniformizer for each unit $u$ of the integers.
3. (B) Show that the valuation $v(f) = e^{-\operatorname{ord}_0(f)}$ on $k((X))$ with values in $\mathbb{R}_{\ge 0}$ is discrete and has rank one.
4. (B) Let $\Gamma = \mathbb{Z} \times \mathbb{Z}$ with the lexicographic order. Give a valuation on $k(X, Y)$ with values in $\Gamma$ and show that it does not have rank one.
5. (B) Prove that $\operatorname{ord}_p(rs) = \operatorname{ord}_p(r) + \operatorname{ord}_p(s)$ for a prime $p$ of a domain, and find a counterexample for an irreducible element that is not prime.
6. (C) Prove that the ring of integers of a valuation with value group $\mathbb{Q}$ has a maximal ideal $\mathfrak m$ with $\mathfrak m^2 = \mathfrak m$.
