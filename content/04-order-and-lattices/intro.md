# Order and lattices

This volume teaches the order theory that the other volumes use. It starts with preorders, partial orders and linear orders, and then shows monotone functions, lattices, complete lattices and the supremum of a set of real numbers. It also shows Galois connections, intervals and ordered groups with the absolute value. Read Volume 1 first, because this volume uses its notation for sets, functions and classes. The analysis and the topology volumes use the supremum, the intervals and the absolute value of this volume.
