## Galois insertions and closure operators

### Overview

A Galois connection $l \dashv u$ gives two composites, $u \circ l$ and $l \circ u$. The subgroup generated by a set and the carrier of a subgroup are a Galois connection from sets to subgroups, and the subgroup generated by the carrier of $H$ is $H$ again. So $l \circ u$ is the identity, and the connection is a *Galois insertion*. The other composite sends a set $S$ to the carrier of the subgroup it generates. This map is extensive, monotone and idempotent: it is a *closure operator*.

The section proves that $u \circ l$ is always a closure operator, that the closed elements of a closure operator on a complete lattice form a complete lattice, and that a Galois insertion carries a complete lattice structure from $\alpha$ to $\beta$. These facts explain why the subgroups and the closed sets of a topology form complete lattices.

### Definitions

In this section $\alpha$ and $\beta$ are partial orders unless the text says otherwise.

**Definition (Galois insertion and coinsertion).** A *Galois insertion* is a Galois connection $l : \alpha \to \beta$, $u : \beta \to \alpha$ with $l(u(b)) = b$ for each $b \in \beta$. A *Galois coinsertion* is a Galois connection with $u(l(a)) = a$ for each $a \in \alpha$.

By the counit, a connection is an insertion if and only if $b \le l(u(b))$ for each $b$.

::: mathlib
`GaloisInsertion` · `Mathlib.Order.GaloisConnection.Defs`

The structure has four fields: `gc : GaloisConnection l u`, `le_l_u : ∀ x, x ≤ l (u x)`, and a function `choice : ∀ x, u (l x) ≤ x → β` with `choice_eq : choice a h = l a`. The choice function gives an element of $\beta$ equal to $l(a)$ when $a$ is closed, with better definitional properties: for a subgroup it can return the subgroup with the given carrier, and not the subgroup generated by it. The lemma `GaloisInsertion.l_u_eq` states $l(u(b)) = b$. To build an insertion from a connection without a special choice, use `GaloisConnection.toGaloisInsertion`.

**Definition (Closure operator).** A *closure operator* on a partial order $\alpha$ is a map $c : \alpha \to \alpha$ such that, for all $x, y$:

1. $c$ is monotone: $x \le y$ implies $c(x) \le c(y)$;
2. $c$ is extensive: $x \le c(x)$;
3. $c$ is idempotent: $c(c(x)) = c(x)$.

An element $x$ is *closed* if $c(x) = x$.

The model is the closure of a set in a topological space. A monotone idempotent map with $c(x) \le x$ is a *kernel operator*, with the interior of a set as the model.

### Theorems and proofs

**Theorem (Three forms of an insertion).** Let $l : \alpha \to \beta$ and $u : \beta \to \alpha$ be a Galois connection between partial orders. The following are equivalent:

1. $l(u(b)) = b$ for each $b$;
2. $l$ is surjective;
3. $u$ is injective.

*Proof.* (1) implies (2): each $b$ is the image $l(u(b))$. (1) implies (3): if $u(b) = u(b')$, then $b = l(u(b)) = l(u(b')) = b'$.

(2) implies (1): let $b = l(a)$. By the triangle identity of the previous section, $l(u(l(a))) = l(a)$, that is $l(u(b)) = b$.

(3) implies (1): by the other triangle identity, $u(l(u(b))) = u(b)$. Since $u$ is injective, $l(u(b)) = b$. $\square$

**Theorem (The closure operator of a connection).** Let $l : \alpha \to \beta$ and $u : \beta \to \alpha$ be a Galois connection. Then $c = u \circ l$ is a closure operator on $\alpha$. An element $x \in \alpha$ is closed for $c$ if and only if $x = u(b)$ for some $b \in \beta$.

*Proof.* The map $c$ is a composite of two monotone maps, so it is monotone. The unit says $x \le u(l(x)) = c(x)$, so $c$ is extensive. For idempotence, the triangle identity $u(l(u(b))) = u(b)$ at the point $b = l(x)$ gives $u(l(u(l(x)))) = u(l(x))$, that is $c(c(x)) = c(x)$.

If $x$ is closed, then $x = u(l(x))$ is in the range of $u$. Conversely, if $x = u(b)$, then $c(x) = u(l(u(b))) = u(b) = x$, by the triangle identity. $\square$

Dually, $l \circ u$ is a kernel operator on $\beta$. For an insertion it is the identity, and for a coinsertion $u \circ l$ is the identity.

**Theorem (The closure is the least closed element above).** Let $c$ be a closure operator on $\alpha$. For each $x$ and each closed $y$, $c(x) \le y$ if and only if $x \le y$. So $c(x)$ is the least closed element above $x$.

*Proof.* If $c(x) \le y$, then $x \le c(x) \le y$. If $x \le y$, then $c(x) \le c(y) = y$, by monotonicity and because $y$ is closed. The element $c(x)$ is closed, since $c(c(x)) = c(x)$, and it is above $x$. Each closed $y$ above $x$ is above $c(x)$. $\square$

So $c$, as a map onto the set of closed elements, is the lower adjoint of the injective inclusion of this set into $\alpha$, and this is a Galois insertion. Every Galois connection gives a closure operator, and every closure operator comes from a Galois insertion.

**Theorem (Closed elements in a complete lattice).** Let $\alpha$ be a complete lattice and let $c$ be a closure operator on $\alpha$.

1. The infimum of any set of closed elements is closed.
2. The closed elements, with the order of $\alpha$, form a complete lattice. The infimum of a set $S$ of closed elements is $\inf S$ computed in $\alpha$, and its supremum is $c(\sup S)$.

*Proof.* 1. Let $S$ be a set of closed elements and $m = \inf S$. For each $y \in S$, $m \le y$, so $c(m) \le c(y) = y$. So $c(m)$ is a lower bound of $S$, and $c(m) \le m$. Extensivity gives $m \le c(m)$, so $c(m) = m$.

2. By part 1, $\inf S$ is closed. It is below each element of $S$, and each closed lower bound of $S$ is below it, because it is the greatest lower bound in $\alpha$. So it is the infimum of $S$ in the closed elements. For the supremum, $c(\sup S)$ is closed. For $y \in S$, $y \le \sup S \le c(\sup S)$, so it is an upper bound of $S$. If $z$ is a closed upper bound of $S$, then $\sup S \le z$, and the theorem above gives $c(\sup S) \le z$. So $c(\sup S)$ is the least closed upper bound. $\square$

The converse of part 1 holds too. Let $M \subseteq \alpha$ be closed under all infima, including the empty infimum $\top$. Define $c(x) = \inf\{y \in M : x \le y\}$. Then $c(x) \in M$ and $x \le c(x)$, because $x$ is a lower bound of the set. If $x \le x'$, the set for $x'$ is contained in the set for $x$, so $c(x) \le c(x')$. If $x \in M$, then $x$ is in its own set, so $c(x) \le x$ and $c(x) = x$. With $c(x) \in M$ this gives $c(c(x)) = c(x)$. So $c$ is a closure operator, and its closed elements are exactly $M$. A set closed under all infima is a *Moore family*, after E. H. Moore.

**Theorem (A Galois insertion lifts a complete lattice).** Let $l : \alpha \to \beta$, $u : \beta \to \alpha$ be a Galois insertion, and let $\alpha$ be a complete lattice. Then $\beta$ is a complete lattice. For $S \subseteq \beta$, $\sup S = l(\sup u(S))$ and $\inf S = l(\inf u(S))$, and $u(\inf S) = \inf u(S)$.

*Proof.* Let $c = u \circ l$. By the theorem on the closure operator of a connection, the closed elements of $c$ are the range of $u$. The map $u$ reflects the order: if $u(b) \le u(b')$, then $b = l(u(b)) \le l(u(b')) = b'$, because $l$ is monotone. So $u$ is an order isomorphism from $\beta$ onto the closed elements, with inverse $l$ on the closed elements. The closed elements form a complete lattice by the theorem above, and an order isomorphism carries suprema and infima. So $\beta$ is a complete lattice.

The supremum of $u(S)$ in the closed elements is $c(\sup u(S))$, so the supremum of $S$ in $\beta$ is $l(c(\sup u(S))) = l(u(l(\sup u(S)))) = l(\sup u(S))$, by the triangle identity. The infimum of $u(S)$ in the closed elements is $\inf u(S)$, which is closed, so it equals $u(b)$ for one $b$, and $\inf S = l(u(b)) = l(\inf u(S))$. Then $u(\inf S) = u(b) = \inf u(S)$. $\square$

### Examples

**Example (The subgroup generated by a set).** Let $G$ be a group. For a subset $S$ let $\langle S \rangle$ be the subgroup generated by $S$, and for a subgroup $H$ let $|H|$ be its carrier set. Then $\langle S \rangle \le H \iff S \subseteq |H|$, because $\langle S \rangle$ is the smallest subgroup that contains $S$. Since $\langle |H| \rangle = H$, this is an insertion, and the theorem on lifting says that the subgroups form a complete lattice with $H \sqcap K = H \cap K$ and $H \sqcup K = \langle H \cup K \rangle$. In $\mathbb{Z}$, the subgroups are $n\mathbb{Z}$, and $4\mathbb{Z} \sqcap 6\mathbb{Z} = 12\mathbb{Z}$, $4\mathbb{Z} \sqcup 6\mathbb{Z} = 2\mathbb{Z}$. The union $4\mathbb{Z} \cup 6\mathbb{Z}$ is not a subgroup, since $4 + 6 = 10$ is in neither part. In Mathlib the insertion is `Subgroup.gi`, and the condition is `Subgroup.closure_le`.

**Example (Closed sets of a topology).** Let $X$ be a topological space. The closure $\overline{A}$ of a set is a closure operator on the subsets of $X$, and its closed elements are the closed sets. The supremum of a family of closed sets in the lattice of closed sets is the closure of the union, and the union need not be closed: in $\mathbb{R}$, the sets $F_n = [1/n, 1]$ are closed, $\bigcup_n F_n = (0, 1]$ is not closed, and $\sup_n F_n = [0, 1]$ in the lattice of closed sets. In Mathlib the insertion from sets to the type `TopologicalSpace.Closeds X` is `TopologicalSpace.Closeds.gi`.

**Example (The floor gives a coinsertion).** The cast $\iota : \mathbb{Z} \to \mathbb{R}$ and the floor form a Galois connection, by the previous section. Here $u(l(n)) = \lfloor \iota(n) \rfloor = n$, so it is a coinsertion: the cast is injective and the floor is surjective. The other composite $x \mapsto \iota(\lfloor x \rfloor)$ is a kernel operator on $\mathbb{R}$. Its fixed points are the integers. The ceiling and the cast give a connection $\lceil \cdot \rceil \dashv \iota$ in the other direction. Here $\lceil \iota(n) \rceil = n$ is $l(u(n)) = n$, so it is an insertion, and its closure operator is $x \mapsto \iota(\lceil x \rceil)$ on $\mathbb{R}$.

**Example (A double polar).** In the polarity of a relation $R \subseteq X \times Y$ from the previous section, the composite $A \mapsto A^{\triangleright\triangleleft}$ is a closure operator on the subsets of $X$. For $X = Y = \mathbb{R}^n$ and orthogonality, $A^{\triangleright\triangleleft} = (A^\perp)^\perp$, and this is the span of $A$. The closed sets are exactly the subspaces. In Galois theory the closed intermediate fields are the fixed fields of groups of automorphisms.

**Counterexample (Extensive and monotone, not idempotent).** On the subsets of $\mathbb{Z}$ let $f(A) = A \cup (A + 1)$, where $A + 1 = \{a + 1 : a \in A\}$. It is monotone and extensive. It is not idempotent: $f(\{0\}) = \{0, 1\}$ and $f(f(\{0\})) = \{0, 1, 2\}$. So it is not a closure operator. The sets with $f(A) = A$ are the sets with $A + 1 \subseteq A$, for example $\emptyset$, $\mathbb{Z}$ and $[k, \infty) \cap \mathbb{Z}$, and they are closed under intersections. The closure operator of this Moore family is $A \mapsto \bigcup_{k \ge 0} (A + k)$. The map $f$ keeps all unions, so it is a lower adjoint, with an upper adjoint $u$ on the subsets of $\mathbb{Z}$. The closure operator of this connection is $u \circ f$, and not $f$. So idempotence is a separate axiom.

### The library around it

Mathlib builds the lattice of substructures with one pattern, for subgroups, submodules, subrings, ideals and closed sets: a `closure` or `span` function from sets, the coercion `SetLike.coe` back to sets, a lemma `closure_le` that is the condition of the connection, and an insertion `gi`. The induction principle `Subgroup.closure_induction` comes from the same fact: to prove a property for all elements of $\langle S \rangle$, show that the elements with the property form a subgroup $H$ that contains $S$, and use $\langle S \rangle \le H$.

The file `Mathlib.Order.Closure` has the API of closure operators: `ClosureOperator.le_closure`, `ClosureOperator.monotone` and `ClosureOperator.idempotent` for the axioms, `ClosureOperator.closure_sup_closure` for $c(c(x) \sqcup c(y)) = c(x \sqcup y)$, and the constructors `ClosureOperator.mk'` and `ClosureOperator.ofPred`. It also has `LowerAdjoint`, a bundled lower adjoint of a fixed map `u`. The lemma `GaloisInsertion.l_sup_u` states $l(u(a) \sqcup u(b)) = a \sqcup b$.

### Exercises

1. (A) In $\mathbb{Z}$, compute $6\mathbb{Z} \sqcup 10\mathbb{Z}$ and $6\mathbb{Z} \sqcap 10\mathbb{Z}$ in the lattice of subgroups. *Hint:* use the gcd and the lcm.
2. (A) Show that the interior of a set in a topological space is a kernel operator, *Hint:* check the three dual axioms.
3. (B) Show that for a closure operator $c$ on a lattice, $c(c(x) \sqcup c(y)) = c(x \sqcup y)$. *Hint:* $c(x \sqcup y)$ is closed and above $c(x)$ and $c(y)$.
4. (B) Show that a Galois connection is a coinsertion if and only if $l$ is injective. *Hint:* exchange the roles of $l$ and $u$ in the three forms of an insertion.
5. (B) Let $X$ be a set. Show that the equivalence relations on $X$, as subsets of $X \times X$, are closed under all intersections. Describe the join of two equivalence relations. *Hint:* the transitive closure of the union.
6. (B) Let $c$ be a closure operator on the subsets of a finite set $X$ with $c(\{x\}) = \{x\}$ for each $x$ and $c(A \cup B) = c(A) \cup c(B)$. Show that $c$ is the identity. *Hint:* write $A$ as a finite union of singletons.
7. (B) Find the upper adjoint $u$ of the map $f$ of the counterexample, and compute $u(\{0, 1, 2, 5\})$. *Hint:* $f(A) \subseteq B$ if and only if $a \in B$ and $a + 1 \in B$ for each $a \in A$.
8. (C) Let $\alpha$ be a complete lattice. Show that the closure operators on $\alpha$ are in bijection with the subsets of $\alpha$ closed under all infima. Show that this bijection reverses the order: $c \le c'$ pointwise if and only if the closed elements of $c'$ are among the closed elements of $c$. *Hint:* for the order, $c'(x)$ is closed for $c$ and above $x$.
9. (C) Let $l \dashv u$ be a Galois connection between complete lattices. Show that the closed elements of $u \circ l$ and the closed elements of the kernel operator $l \circ u$ are order isomorphic, by $l$ and $u$. *Hint:* the triangle identities.

### Notes and history

Closure operators appear in the work of Moore (1910) on "extended sets" and in the axioms for topology of Kuratowski (1922). Birkhoff's *Lattice Theory* (1940) proved that the closed elements form a complete lattice, and Ore studied closure operators in 1943. The last exercise is the general form of the fundamental theorem of Galois theory, which says that for a finite Galois extension all intermediate fields and all subgroups are closed.

In Mathlib, `Mathlib/Order/Closure.lean` was written by Bhavik Mehta in 2020 and later extended by Yaël Dillies. The choice function of `GaloisInsertion` comes from Lean 3, where it was added so that the infimum of two subgroups has the intersection as its carrier by definition.
