## Topologies defined by an order

### Overview

Section 1 uses one topology on an order, the order topology. A preorder carries other natural topologies, and they are the main tools of domain theory and of the duality theory of lattices. The upper set topology has the upper sets as open sets. The upper topology is generated by the complements of the sets $(-\infty, a]$. The Scott topology has the upper sets that directed suprema cannot enter from outside. The Lawson topology is generated by the Scott topology and the lower topology together. Each of these topologies has a lower or dual form for the order dual.

The library gives each topology twice: as a topology on a type with a name such as `Topology.scott`, and as a predicate class such as `Topology.IsScott`. A type synonym such as `Topology.WithScott` carries the topology as an instance. This section describes this pattern, the four topologies and their comparisons, and the equivalence between Alexandrov-discrete spaces and preorders.

The text uses the specialization order of Chapter 4 and the Alexandrov-discrete spaces of Chapter 1.

### The library around it

#### The pattern: a topology, a class and a synonym

Each module of the section uses the same three parts. Take the lower topology as an example.

- `Topology.lower α` is the topology on a preorder $\alpha$ generated by the sets $(\{x : a \le x\})^c$.
- `Topology.IsLower α` is a class on a type that already has a topology and an order. It says that the topology is the lower topology. The constructor `Topology.IsLower.mk` takes the equality of topologies.
- `Topology.WithLower α` is a type synonym of $\alpha$ with the lower topology as an instance. The equivalences `Topology.WithLower.toLower` and `Topology.WithLower.ofLower` move between $\alpha$ and the synonym, and `Topology.IsLower.withLowerHomeomorph` is the homeomorphism when $\alpha$ already has the lower topology.

The class form lets a type such as $[0, \infty]$ keep its usual instance and still use the theory. The synonym form gives a second topology on a type that has one already. The same pattern gives `Topology.upper`, `Topology.upperSet`, `Topology.lowerSet`, `Topology.scott` and `Topology.lawson`. The dual results come from the order dual: `Topology.isLower_orderDual` says that the lower topology on $\alpha^{\mathrm{op}}$ is the upper topology on $\alpha$.

#### The upper set topology

The upper set topology on a preorder has the upper sets as open sets. The class is `Topology.IsUpperSet`, and `Topology.IsUpperSet.isOpen_iff_isUpperSet` states its definition. Arbitrary intersections of upper sets are upper sets, so the space is Alexandrov-discrete (`Topology.IsUpperSet.toAlexandrovDiscrete`). The smallest neighbourhood of $a$ is $[a, \infty)$, and the neighbourhood filter is principal (`Topology.IsUpperSet.nhds_eq_principal_Ici`). The closure of a set is its lower closure (`Topology.IsUpperSet.closure_eq_lowerClosure`).

The continuous maps are the monotone maps:

$$f \text{ monotone} \iff f \text{ continuous, for the upper set topologies.}$$

This is `Topology.IsUpperSet.monotone_iff_continuous`. *Proof.* If $f$ is monotone, the preimage of an upper set is an upper set. If $f$ is continuous and $a \le b$, then $f^{-1}([f(a), \infty))$ is an open set that contains $a$, so it contains the smallest neighbourhood $[a, \infty)$ of $a$, and $f(a) \le f(b)$.

The specialization order of Chapter 4 gives the order back: in the upper set topology $a$ specializes to $b$ if and only if $b \le a$ (`Topology.IsUpperSet.specializes_iff_le`). This is the content of the equivalence of categories `alexDiscEquivPreord` between Alexandrov-discrete spaces with continuous maps and preorders with monotone maps, in the module `Mathlib.Topology.Order.Category.AlexDisc`. The category `AlexDisc` is built on `TopCat`. The functor to preorders takes the specialization order, and the inverse functor takes the upper set topology. The order isomorphism `orderIsoSpecializationWithUpperSetTopology` and the homeomorphism `homeoWithUpperSetTopologyorderIso` are the unit and the counit. The separation module `Mathlib.Topology.Separation.AlexandrovDiscrete` adds that a T1 Alexandrov-discrete space is discrete (`instDiscreteTopologyOfAlexandrovDiscreteOfT1Space`). The module `Mathlib.Topology.Separation.LinearUpperLowerSetTopology` proves that a linear order with the upper set topology is completely normal (`instCompletelyNormalSpaceOfIsUpperSet`).

#### The lower and upper topologies

The lower topology `Topology.lower α` is the coarsest topology in which each set $[a, \infty)$ is closed. Its closed sets are upper sets (`Topology.IsLower.isUpperSet_of_isClosed`), the closure of a point $a$ is $[a, \infty)$ (`Topology.IsLower.closure_singleton`), and the space is T0 for a partial order (`Topology.IsLower.t0Space`). The finite intersections of the sets $[a, \infty)^c$ form a basis (`Topology.IsLower.isTopologicalBasis`). A map into a space with the lower topology is continuous if and only if the preimage of each $[a, \infty)$ is closed (`Topology.IsLower.continuous_iff_Ici`). A map that preserves all infima between complete lattices with the lower topology is continuous (`sInfHom.continuous`). The dual results for the upper topology have the names `Topology.IsUpper.closure_singleton`, `Topology.IsUpper.continuous_iff_Iic` and so on.

On a linear order the two topologies together give the order topology of Section 1:

$$\mathrm{lower}(\alpha) \sqcap \mathrm{upper}(\alpha) = \text{order topology of } \alpha.$$

This is `Topology.lower_inf_upper_eq_preorderTopology`. In the lattice of topologies a smaller topology is finer, so the infimum is the topology generated by both. The order topology is generated by the open rays, and the open rays $(a, \infty)$ and $(-\infty, a)$ are the complements of the closed rays that generate the two topologies, since the order is linear.

#### The Scott and Lawson topologies

The Scott topology is the topology of domain theory, where an element is an approximation and a directed supremum is a limit of approximations. A set $D$ of directed sets is a parameter. The Scott-Hausdorff topology `Topology.scottHausdorff α D` has as open sets the sets $u$ such that, for each directed $d \in D$ with a least upper bound $a \in u$, some $b \in d$ satisfies $[b, \infty) \cap d \subseteq u$ (`Topology.IsScottHausdorff.isOpen_iff`). The Scott topology `Topology.scott α D` is the supremum of the upper set topology and the Scott-Hausdorff topology, so its open sets are the upper sets that are Scott-Hausdorff open. For all directed sets, `Topology.IsScott α Set.univ` is the usual Scott topology. Its closed sets are the lower sets closed under directed suprema:

$$s \text{ closed} \iff s \text{ is a lower set and } s \text{ contains the suprema of its directed subsets.}$$

This is `Topology.IsScott.isClosed_iff_isLowerSet_and_dirSupClosed`, with the predicate `DirSupClosed` of the order library. The closure of a point $a$ is $(-\infty, a]$ (`Topology.IsScott.closure_singleton`).

The continuous maps for the Scott topology are the Scott-continuous maps, the maps that keep the least upper bounds of directed sets:

$$f \text{ Scott-continuous} \iff f \text{ continuous, for the Scott topologies.}$$

This is `Topology.IsScott.scottContinuousOn_iff_continuous`. Its hypothesis says that the family $D$ contains each pair $\{a, b\}$ with $a \le b$, which makes each Scott-continuous map monotone. A continuous map between Scott topologies is monotone (`Topology.IsScott.monotone_of_continuous`). On a complete linear order the Scott topology is the upper topology (`Topology.IsScott.scott_eq_upper_of_completeLinearOrder`).

The module `Mathlib.Topology.OmegaCompletePartialOrder` has an older form of the Scott topology for the $\omega$-complete partial orders of the semantics of programs. The predicate `Scott.IsOpen` uses chains in place of directed sets, and `Topology.IsScott.ωScottContinuous_iff_continuous` links it with the general theory.

The Lawson topology `Topology.lawson α` is the infimum of the lower topology and the Scott topology, that is the topology generated by the open sets of both. Its class is `Topology.IsLawson`. It is finer than both (`Topology.lawson_le_scott`, `Topology.lawson_le_lower`), and on a partial order it is T1 (`Topology.IsLawson.toT1Space`), while the Scott topology is only T0. The basic open sets are the differences $u \setminus \uparrow t$ of a Scott open set $u$ and the upper closure of a finite set $t$ (`Topology.IsLawson.isTopologicalBasis`). An upper set is Lawson open if and only if it is Scott open (`Topology.lawsonOpen_iff_scottOpen_of_isUpperSet`).

#### Common errors

1. In the lattice of topologies a smaller topology has more open sets. So `Topology.lawson_le_scott` says that the Lawson topology is finer than the Scott topology, and the infimum in `Topology.lower_inf_upper_eq_preorderTopology` is the topology generated by both.
2. A type such as $\mathbb{R}$ already has its order topology as an instance. To use the Scott topology on it, use the synonym `Topology.WithScott`. Do not add a second instance of a topology on the type.
3. The specialization order of the upper set topology is the reverse of the order: $a$ specializes to $b$ when $b \le a$. The lower set topology gives the order itself (`Topology.IsLowerSet.specializes_iff_le`).

### Exercises

1. (A) Describe the upper set topology, the upper topology and the Scott topology on the three-element chain $0 < 1 < 2$, and show that they agree.
2. (A) Prove that a continuous map between two preorders with their upper set topologies is monotone, from the smallest neighbourhoods.
3. (B) Show that on $\mathbb{N} \cup \{\infty\}$ the set $\{\infty\}$ is open in the upper set topology and not in the Scott topology.
4. (B) Prove that the Scott topology of a partial order is T0, and that it is T1 only if the order is discrete.
5. (B) Prove `Topology.lower_inf_upper_eq_preorderTopology` for $\mathbb{R}$ from the subbases of the three topologies.
6. (C) Prove that a map between complete lattices that preserves all directed suprema is continuous for the Scott topologies, and give a monotone map that is not.
