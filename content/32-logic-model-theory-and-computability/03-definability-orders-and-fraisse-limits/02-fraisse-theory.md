## Fraïssé theory

### Overview

The proof of Cantor's theorem in Section 1 uses only two facts about the rationals: each finite part of a countable dense linear order without endpoints is a finite linear order, and each finite partial isomorphism extends by one more point. Fraïssé saw that the same argument works for any class of finite or finitely generated structures that is closed in three ways. Such a class has a unique countable structure that contains every member of the class, contains nothing else, and is as symmetric as possible. This structure is the Fraïssé limit of the class.

This section defines the age of a structure, the three closure properties of a class, ultrahomogeneous structures and Fraïssé limits. It proves which classes are ages of countable structures, that the age of an ultrahomogeneous structure has the amalgamation property, and that two Fraïssé limits of one class are isomorphic. The rationals are the Fraïssé limit of the finite linear orders, and Cantor's theorem comes back as a corollary.

### Definitions

Fix a language $L$. A class of structures is a set $K$ of $L$-structures, and a structure $A$ is finitely generated if $A$ is the substructure generated by a finite subset of $A$ (Chapter 1). In a language with no function symbols and no constant symbols, the substructure generated by a set is the set itself, so finitely generated means finite.

**Definition (Age).** The age of an $L$-structure $M$ is the class of finitely generated $L$-structures $A$ that have an embedding $A \hookrightarrow M$.

**Definition (Hereditary property).** A class $K$ is hereditary if $\operatorname{age}(B) \subseteq K$ for each $B \in K$. So each finitely generated structure that embeds into a member of $K$ is in $K$.

**Definition (Joint embedding property).** A class $K$ has the joint embedding property if for all $A, B \in K$ there is $C \in K$ with embeddings $A \hookrightarrow C$ and $B \hookrightarrow C$.

**Definition (Amalgamation property).** A class $K$ has the amalgamation property if for all $A, B, C \in K$ and embeddings $f \colon A \hookrightarrow B$ and $g \colon A \hookrightarrow C$ there are $D \in K$ and embeddings $f' \colon B \hookrightarrow D$ and $g' \colon C \hookrightarrow D$ with $f' \circ f = g' \circ g$.

**Definition (Fraïssé class).** A class $K$ is a Fraïssé class if it is nonempty, each member is finitely generated, $K$ contains only countably many isomorphism classes, and $K$ has the hereditary, joint embedding and amalgamation properties.

**Definition (Ultrahomogeneous structure).** A structure $M$ is ultrahomogeneous if for each finitely generated substructure $S \subseteq M$ and each embedding $f \colon S \hookrightarrow M$ there is an automorphism $g$ of $M$ with $g|_S = f$.

**Definition (Fraïssé limit).** Let $L$ have countably many function symbols and let $M$ be countable. Then $M$ is a Fraïssé limit of $K$ if $M$ is ultrahomogeneous and $\operatorname{age}(M) = K$.

**Definition (Extension pair).** A finitely generated partial isomorphism from $M$ to $N$ is an isomorphism $f \colon S \to T$ between a finitely generated substructure $S \subseteq M$ and a substructure $T \subseteq N$. The pair $(M, N)$ is an extension pair if for each such $f$ and each $m \in M$ there is a finitely generated partial isomorphism $f' \supseteq f$ with $m \in \operatorname{dom} f'$.

### Theorems and proofs

**Proposition (Properties of an age).** Let $M$ be an $L$-structure. Then $\operatorname{age}(M)$ is nonempty, closed under isomorphism, hereditary and has the joint embedding property. If $M \hookrightarrow N$, then $\operatorname{age}(M) \subseteq \operatorname{age}(N)$, and isomorphic structures have the same age.

*Proof.* The substructure of $M$ generated by $\emptyset$ is finitely generated and embeds into $M$ by inclusion, so it is in the age. If $A \cong A'$, then $A'$ is finitely generated and the composite $A' \cong A \hookrightarrow M$ is an embedding. If $B \in \operatorname{age}(M)$ by $e \colon B \hookrightarrow M$ and $A \in \operatorname{age}(B)$ by $d$, then $e \circ d \colon A \hookrightarrow M$, so the age is hereditary. For joint embedding, let $e_A \colon A \hookrightarrow M$ and $e_B \colon B \hookrightarrow M$. The images are finitely generated, so the substructure $C$ generated by both images is finitely generated, $C$ embeds into $M$ by inclusion, and $A$ and $B$ embed into $C$. If $h \colon M \hookrightarrow N$, compose each $A \hookrightarrow M$ with $h$. An isomorphism gives the inclusion in both directions. $\square$

**Proposition (Countably many types in an age).** If $M$ is countable, then $\operatorname{age}(M)$ has countably many isomorphism classes.

*Proof.* Each $A \in \operatorname{age}(M)$ is isomorphic to the image of its embedding, which is a finitely generated substructure of $M$, and so it is the substructure $\langle F \rangle$ generated by a finite set $F \subseteq M$. The map $F \mapsto [\langle F \rangle]$ from the finite subsets of $M$ onto the isomorphism classes of the age is surjective. A countable set has countably many finite subsets. $\square$

**Theorem (Ages of countable structures).** Let $L$ have countably many function symbols. A class $K$ is the age of a countable $L$-structure if and only if $K$ is nonempty, closed under isomorphism, has countably many isomorphism classes, consists of finitely generated structures, and is hereditary with the joint embedding property.

*Proof.* The two propositions above give the conditions for an age. For the converse, choose representatives $A_0, A_1, A_2, \dots$ of the isomorphism classes of $K$, repeating one if there are finitely many. Put $B_0 = A_0$. Given $B_n \in K$, the joint embedding property gives $B_{n+1} \in K$ with $B_n \hookrightarrow B_{n+1}$ and $A_{n+1} \hookrightarrow B_{n+1}$. Let $M$ be the direct limit of the chain $B_0 \hookrightarrow B_1 \hookrightarrow \cdots$ (Chapter 2). Each $B_n$ is generated by a finite set, and the language has countably many function symbols, so $B_n$ has countably many terms in its generators and is countable. So $M$ is countable. A finitely generated substructure of $M$ has its finitely many generators in the image of one $B_n$, so $\operatorname{age}(M) = \bigcup_n \operatorname{age}(B_n)$. This union is contained in $K$ because $K$ is hereditary, and it contains each $A_n$ because $A_n \hookrightarrow B_n$. As $K$ is closed under isomorphism, $\operatorname{age}(M) = K$. $\square$

**Lemma (Extension of embeddings).** Let $M$ be ultrahomogeneous, let $S$ be finitely generated, let $f \colon S \hookrightarrow M$ and $g \colon S \hookrightarrow T$ be embeddings, and let $T$ embed into $M$ by some $r$. Then there is $f' \colon T \hookrightarrow M$ with $f' \circ g = f$.

*Proof.* The image $r(g(S))$ is a finitely generated substructure of $M$. The map $f \circ (r \circ g)^{-1}$ is an embedding of it into $M$, so ultrahomogeneity gives an automorphism $\sigma$ that extends it. Put $f' = \sigma \circ r$. Then $f'(g(s)) = \sigma(r(g(s))) = f(s)$. $\square$

**Theorem (Ultrahomogeneity and extension).** Let $M$ be countably generated. Then $M$ is ultrahomogeneous if and only if $(M, M)$ is an extension pair.

*Proof.* Let $M$ be ultrahomogeneous, let $f \colon S \to T$ be a finitely generated partial isomorphism and let $m \in M$. Extend $f$ to an automorphism $\sigma$ and restrict $\sigma$ to the substructure generated by $S$ and $m$. This is finitely generated and extends $f$. Conversely, let $(M, M)$ be an extension pair and let $f \colon S \hookrightarrow M$ with $S$ finitely generated. Enumerate a countable generating set $m_0, m_1, \dots$ of $M$. The extension property applied to $f$ gives $f_1 \supseteq f$ with $m_0$ in the domain. The extension property applied to $f_1^{-1}$ gives $f_2 \supseteq f_1$ with $m_0$ in the range. Continue so that $m_k$ enters the domain at step $2k+1$ and the range at step $2k+2$. The union $\sigma = \bigcup_n f_n$ is a partial isomorphism. Its domain and its range are substructures that contain all generators, so both are $M$, and $\sigma$ is an automorphism that extends $f$. $\square$

**Theorem (Amalgamation in an ultrahomogeneous structure).** If $M$ is ultrahomogeneous, then $\operatorname{age}(M)$ has the amalgamation property. If $M$ is also countable, then $\operatorname{age}(M)$ is a Fraïssé class.

*Proof.* Let $A, B, C \in \operatorname{age}(M)$ with $f \colon A \hookrightarrow B$, $g \colon A \hookrightarrow C$, and choose $e_B \colon B \hookrightarrow M$ and $e_C \colon C \hookrightarrow M$. The substructure $S = e_B(f(A))$ is finitely generated. The map $e_C \circ g \circ (e_B \circ f)^{-1} \colon S \hookrightarrow M$ extends to an automorphism $\sigma$, so $\sigma \circ e_B \circ f = e_C \circ g$. Let $D$ be the substructure generated by $\sigma(e_B(B))$ and $e_C(C)$. It is finitely generated, so $D \in \operatorname{age}(M)$. Put $f' = \sigma \circ e_B$ and $g' = e_C$, with values in $D$. Then $f' \circ f = g' \circ g$. For the second statement, the age of a countable structure has countably many isomorphism classes, and the other conditions come from the properties of an age. $\square$

**Lemma (Fraïssé limits form extension pairs).** Let $M$ and $N$ be Fraïssé limits of $K$. Then $(M, N)$ is an extension pair.

*Proof.* Let $f \colon S \to T$ be a finitely generated partial isomorphism from $M$ to $N$, and let $m \in M$. The substructure $S'$ generated by $S$ and $m$ is finitely generated, so $S' \in \operatorname{age}(M) = K = \operatorname{age}(N)$ by an embedding $e \colon S' \hookrightarrow N$. The map $f \circ (e|_S)^{-1}$ is an embedding of the finitely generated substructure $e(S)$ into $N$. Ultrahomogeneity of $N$ gives an automorphism $\sigma$ of $N$ that extends it. Then $\sigma \circ e$ is an embedding of $S'$ into $N$, and for $s \in S$ it gives $\sigma(e(s)) = f(s)$. Its image is a substructure, so $\sigma \circ e$ is a finitely generated partial isomorphism that extends $f$ and has $m$ in its domain. $\square$

**Theorem (Uniqueness of Fraïssé limits).** Two Fraïssé limits $M$ and $N$ of one class $K$ are isomorphic.

*Proof.* The substructure $M_0 \subseteq M$ generated by $\emptyset$ is finitely generated, so $M_0 \in K = \operatorname{age}(N)$ and an embedding $e \colon M_0 \hookrightarrow N$ exists. So $e$ is a finitely generated partial isomorphism from $M$ to $N$. By the lemma, $(M, N)$ and $(N, M)$ are extension pairs. The back-and-forth construction in the proof of the theorem on ultrahomogeneity and extension, with $M$ and $N$ in place of the two copies of $M$, extends $e$ to an isomorphism $M \cong N$. Both structures are countable, so they are countably generated. $\square$

**Corollary (Cantor's theorem again).** Let $K$ be the class of finite linear orders, as structures in the language of orders. Each countable nonempty model of $\mathrm{DLO}$ is a Fraïssé limit of $K$. So two countable nonempty models of $\mathrm{DLO}$ are isomorphic, and $\mathrm{DLO}$ is $\aleph_0$-categorical.

*Proof.* The language has no function symbols, so finitely generated substructures are finite subsets. Let $P$ be a countable nonempty model of $\mathrm{DLO}$. A finite linear order of size $n$ embeds into $P$, because $P$ is infinite and each $n$-element subset is order isomorphic to it, and each finite subset of $P$ is a finite linear order. So $\operatorname{age}(P) = K$. Step 1 of the proof of Cantor's theorem in Section 1 says that $(P, P)$ is an extension pair, so $P$ is ultrahomogeneous by the theorem above. The uniqueness theorem gives the isomorphism. $\square$

### Examples

**Example (Finite linear orders).** The class $K$ of finite linear orders is a Fraïssé class with Fraïssé limit $(\mathbb{Q}, \leq)$. Directly, amalgamation works as follows: given $f \colon A \hookrightarrow B$ and $g \colon A \hookrightarrow C$, take $D$ to be $B \sqcup C$ with $f(a)$ and $g(a)$ identified. The cut of a point $x \in D$ is the set of $a \in A$ whose image lies below $x$. Order $D$ first by cut, then by the order of $B$ or of $C$ inside each of them, and put $b < c$ when $b \in B$ and $c \in C$ have the same cut. Ultrahomogeneity of $\mathbb{Q}$ is visible too: an order isomorphism between finite sets $a_1 < \cdots < a_n$ and $b_1 < \cdots < b_n$ extends to the piecewise linear automorphism that sends $[a_i, a_{i+1}]$ linearly onto $[b_i, b_{i+1}]$ and translates the two unbounded pieces.

**Example (Pure sets).** In the empty language, a structure is a set, an embedding is an injection, and the age of a set is the class of finite sets of size at most its cardinality. Each countably infinite set is ultrahomogeneous, since a bijection between finite subsets extends to a permutation. So $\mathbb{N}$ is a Fraïssé limit of the class of finite sets, and this class is Fraïssé.

**Counterexample (The integers).** The order $(\mathbb{Z}, \leq)$ is not ultrahomogeneous. The map $0 \mapsto 0$, $2 \mapsto 1$ is an embedding of $\{0, 2\}$, but an automorphism of $\mathbb{Z}$ is a translation, and no translation does this. Its age is the class of finite linear orders, but $\mathbb{Z}$ is not a Fraïssé limit of that class.

**Counterexample (Bounded linear orders).** The class of linear orders with at most $3$ elements is hereditary and has the joint embedding property, but not the amalgamation property. With $A = \{a\}$, $B = \{a < b_1 < b_2\}$ and $C = \{c < a\}$, an amalgam contains $c < a < b_1 < b_2$, which has $4$ elements.

Common errors of a learner: The first error is to confuse `L.age M`, a set of bundled structures, with a set of substructures of `M`; membership needs an embedding, not an inclusion. The second error is to forget that a class `K` in Mathlib need not be closed under isomorphism; a hypothesis such as `IsFraisse K` gives this through `IsFraisse.is_equiv_invariant`, but a bare `Set` does not. The third error is to look for an existence theorem for Fraïssé limits; this edition has only uniqueness. The fourth error is to state `IsFraisseLimit` without the instance on the function symbols, which Lean then cannot find.

### Exercises

1. (A) Prove that the age of a finite structure in a language with no function symbols is the class of structures isomorphic to its substructures. Hint: finitely generated means finite here.
2. (A) Show that the class of finite sets in the empty language has the amalgamation property. Hint: take the pushout of sets, that is, glue $B$ and $C$ along the images of $A$.
3. (A) Prove that a countable structure $M$ is a Fraïssé limit of $\operatorname{age}(M)$ if and only if it is ultrahomogeneous. Hint: unfold the definition.
4. (B) Prove that the class of finite simple graphs is a Fraïssé class. Hint: for amalgamation, glue $B$ and $C$ along $A$ and add no new edges.
5. (B) Let $M$ be a Fraïssé limit and let $a, b \in M$ generate isomorphic substructures by a map with $a \mapsto b$. Prove that $a$ and $b$ satisfy the same formulas. Hint: an automorphism moves $a$ to $b$, and automorphisms preserve realization.
6. (C) Prove that the class of finite linear orders with a unary predicate is a Fraïssé class, and describe its Fraïssé limit. Hint: the limit is $\mathbb{Q}$ with a set $P$ such that $P$ and its complement are dense in each interval.

### Notes and history

Fraïssé introduced ages, the amalgamation property and the limit construction in 1954, and he proved that a countable ultrahomogeneous structure is determined by its age. The rationals are the first example. The Fraïssé limit of the finite simple graphs is the random graph of Rado, and the index of this edition has no declaration for it. Hodges' book Model Theory gives the standard modern account, with the existence theorem that Mathlib still lacks.

The Mathlib file `Mathlib.ModelTheory.Fraisse` is by Aaron Anderson and Gabin Kolly, read from its header.
