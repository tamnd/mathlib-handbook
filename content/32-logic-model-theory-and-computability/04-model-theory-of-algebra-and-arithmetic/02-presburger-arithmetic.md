## Presburger arithmetic

### Overview

Presburger arithmetic is the first-order theory of the natural numbers with $0$, $1$ and addition, and without multiplication. Its definable sets have a complete description. A subset of $\mathbb{N}^k$ is definable if and only if it is semilinear, that is, a finite union of sets of the form $a + \mathbb{N} p_1 + \cdots + \mathbb{N} p_m$. In dimension one, the semilinear sets are the ultimately periodic sets. So the set of even numbers is definable, and the set of squares is not. As a consequence, multiplication is not definable from addition.

This section sets up the language and its structure on $\mathbb{N}$, computes the realization of terms, defines linear and semilinear sets, proves that semilinear sets are definable, proves the closure properties that give the converse, and proves the description in dimension one. The index of this edition has no declaration for the theory of Presburger arithmetic, for its quantifier elimination or for its completeness. Mathlib studies the standard model $\mathbb{N}$ only.

### Definitions

**Definition (Language of Presburger arithmetic).** The language $L_{\mathrm{Pr}}$ has the constant symbols $0$ and $1$, one binary function symbol $+$, and no relation symbols.

Each type $M$ with $0$, $1$ and $+$ is an $L_{\mathrm{Pr}}$-structure, with each symbol interpreted by the operation of the same name. In particular $\mathbb{N}$ is a structure.

**Definition (Numerals and multiples).** For $n \in \mathbb{N}$, the numeral $\underline{n}$ is the term $0 + 1 + \cdots + 1$ with $n$ ones, and for a term $t$, the term $n \cdot t$ is $0 + t + \cdots + t$ with $n$ summands. These are abbreviations: $n \cdot t$ is not multiplication by a symbol.

**Definition (Linear set).** Let $M$ be a commutative monoid, written additively. A set $S \subseteq M$ is linear if there are $a \in M$ and a finite set $T \subseteq M$ with $S = a + \langle T \rangle$, where $\langle T \rangle$ is the submonoid generated by $T$. For $M = \mathbb{N}^k$ and $T = \{p_1, \dots, p_m\}$, $$S = \{a + \lambda_1 p_1 + \cdots + \lambda_m p_m : \lambda_1, \dots, \lambda_m \in \mathbb{N}\}.$$ The vector $a$ is the base and the $p_j$ are the periods.

**Definition (Semilinear set).** A set is semilinear if it is a finite union of linear sets.

**Definition (Proper linear set).** A linear set is proper if its periods are linearly independent over $\mathbb{N}$.

**Definition (Ultimately periodic set).** A set $S \subseteq \mathbb{N}$ is ultimately periodic if there are $k$ and $p > 0$ with $x \in S \iff x + p \in S$ for all $x \geq k$.

### Theorems and proofs

**Lemma (Terms are affine).** Let $\alpha$ be finite and let $t$ be a term in the variables $\alpha$, with parameters from a set $A \subseteq \mathbb{N}$. There are $k \in \mathbb{N}$ and $u \in \mathbb{N}^{\alpha}$ such that $t^{\mathbb{N}}[v] = k + \sum_{i} u_i v_i$ for all $v \in \mathbb{N}^{\alpha}$.

*Proof.* Induction on $t$. A variable $x_i$ has $k = 0$ and $u = e_i$. The constants $0$ and $1$ and a parameter $c_a$ have $u = 0$ and $k = 0$, $1$ or $a$. If $t_1$ has $(k_1, u_1)$ and $t_2$ has $(k_2, u_2)$, then $t_1 + t_2$ has $(k_1 + k_2, u_1 + u_2)$. $\square$

**Theorem (Semilinear sets are definable).** Let $\alpha$ be finite. Each semilinear subset of $\mathbb{N}^{\alpha}$ is $\emptyset$-definable in $\mathbb{N}$.

*Proof.* Let $S = a + \mathbb{N} p_1 + \cdots + \mathbb{N} p_m$. The formula $$\exists y_1 \cdots \exists y_m \bigwedge_{i \in \alpha} \Big(x_i = \underline{a_i} + p_{1,i} \cdot y_1 + \cdots + p_{m,i} \cdot y_m\Big)$$ holds at $v$ if and only if $v = a + \sum_j \lambda_j p_j$ for some $\lambda \in \mathbb{N}^m$, that is, $v \in S$. A finite union of linear sets is defined by the disjunction of their formulas. $\square$

**Theorem (Solutions of a linear system).** Let $U$ and $W$ be $r \times k$ matrices over $\mathbb{N}$ and $a, b \in \mathbb{N}^r$. The set $E = \{x \in \mathbb{N}^k : a + U x = b + W x\}$ is semilinear. In particular, for $r = 1$, the solution set of one equation $a + u \cdot x = b + w \cdot x$ is semilinear.

*Proof.* Order $\mathbb{N}^k$ coordinatewise. By Dickson's lemma, each set of vectors has only finitely many minimal elements, and each element lies above a minimal one. Let $H = \{x : U x = W x\}$. It is a submonoid. Let $T$ be the finite set of minimal elements of $H \setminus \{0\}$. Each $x \in H$ lies in $\langle T \rangle$, by induction on $\sum_i x_i$: if $x \neq 0$, choose $t \in T$ with $t \leq x$; then $U (x - t) = U x - U t = W x - W t = W (x - t)$, so $x - t \in H$ has a smaller sum. So $H = \langle T \rangle$. Let $B$ be the finite set of minimal elements of $E$. For $x \in E$, choose $s \in B$ with $s \leq x$. Subtract $a + U s = b + W s$ from $a + U x = b + W x$ to get $U (x - s) = W (x - s)$, so $x \in s + H$. Conversely $s + H \subseteq E$. So $E = \bigcup_{s \in B} (s + \langle T \rangle)$. $\square$

**Theorem (Closure properties).** In $\mathbb{N}^k$, semilinear sets are closed under finite unions, images under additive maps $\mathbb{N}^k \to \mathbb{N}^l$, projections and intersections.

*Proof.* Unions hold by definition. An additive map $f$ sends $a + \langle T \rangle$ to $f(a) + \langle f(T) \rangle$, and a projection is an additive map. Intersection distributes over union, so it is enough to intersect two linear sets $a + \langle p_1, \dots, p_m \rangle$ and $b + \langle q_1, \dots, q_n \rangle$. A point is in both if and only if it is $a + \sum_j \lambda_j p_j$ for a solution $(\lambda, \mu) \in \mathbb{N}^{m+n}$ of the system $a + \sum_j \lambda_j p_j = b + \sum_l \mu_l q_l$ in $\mathbb{N}^k$. The solutions form a semilinear set by the previous theorem, and the intersection is its image under the map $(\lambda, \mu) \mapsto a + \sum_j \lambda_j p_j$. This map is additive followed by a translation by $a$, and a translate of a linear set is linear. $\square$

**Remark (Complements).** Semilinear subsets of $\mathbb{N}^k$ are also closed under complements. Mathlib proves this through closure under set difference, with $S^{c} = \mathbb{N}^k \setminus S$. That proof decomposes semilinear sets into finer pieces and is several hundred lines long in `Semilinear.Basic`, and this section does not reproduce it. In dimension one, complements are immediate from the theorem below, since the complement of an ultimately periodic set is ultimately periodic.

**Theorem (Definable sets are semilinear).** Let $\alpha$ be finite and $A \subseteq \mathbb{N}$. A set $S \subseteq \mathbb{N}^{\alpha}$ is $A$-definable in $\mathbb{N}$ if and only if it is semilinear.

*Proof.* One direction is the theorem above on semilinear sets. For the other, prove by induction on a formula $\varphi$ with free variables $x_1, \dots, x_k$ that $\{v \in \mathbb{N}^k : \mathbb{N} \models \varphi[v]\}$ is semilinear. An atomic formula $t_1 = t_2$ becomes $k_1 + u_1 \cdot v = k_2 + u_2 \cdot v$ by the lemma on terms, so it defines a semilinear set by the theorem on linear systems. The formula $\bot$ defines $\emptyset$. The language has no relation symbols. An implication $\varphi \to \psi$ defines $S_{\varphi}^{c} \cup S_{\psi}$. A formula $\forall y\, \varphi$ defines the complement of the projection of $S_{\neg\varphi}$. The closure properties and the remark on complements give each case. $\square$

**Theorem (Dimension one).** A set $S \subseteq \mathbb{N}$ is semilinear if and only if it is ultimately periodic.

*Proof.* Let $S$ be ultimately periodic with $k$ and $p$. Then $$S = (S \cap \{0, \dots, k - 1\}) \cup \bigcup \{ r + \mathbb{N} p : r \in S,\ k \leq r < k + p \},$$ a finite union of linear sets, because each $x \geq k$ in $S$ is $r + \lambda p$ with $k \leq r < k + p$ and $r \in S$. Conversely, a finite union of ultimately periodic sets with data $(k_i, p_i)$ is ultimately periodic with $k = \max k_i$ and $p = \prod p_i$. So it is enough to treat $S = a + \langle p_1, \dots, p_m \rangle$. If all $p_j = 0$, then $S = \{a\}$, with $k = a + 1$ and $p = 1$. Otherwise let $P > 0$ be one of the periods and $g = \gcd(p_1, \dots, p_m)$. Each element of $\langle p_1, \dots, p_m \rangle$ is a multiple of $g$. By Bézout, $g = \sum_j c_j p_j$ with $c_j \in \mathbb{Z}$. Add multiples of $P$ to the coefficients of the other periods to make them nonnegative, and drop the coefficient of $P$. This gives $m_1 \in \langle p_1, \dots, p_m \rangle$ with $m_1 \equiv g \pmod P$. For $0 \leq r < P/g$ put $m_r' = r m_1$, so $m_r' \equiv r g$. Let $N = \max_r m_r'$. If $y \geq N$ is a multiple of $g$, then $y \equiv r g \pmod P$ for some $r$, and $y = m_r' + \lambda P$ with $\lambda \geq 0$, so $y \in \langle p_1, \dots, p_m \rangle$. So for $x \geq a + N$, $x \in S$ if and only if $g$ divides $x - a$, and $S$ is ultimately periodic with $k = a + N$ and period $g$. $\square$

**Corollary (Definable subsets of the natural numbers).** A set $S \subseteq \mathbb{N}$ is definable in $(\mathbb{N}, 0, 1, +)$ with parameters if and only if it is ultimately periodic.

*Proof.* Combine the theorem on definable sets for $\alpha = \{0\}$ with the theorem in dimension one. $\square$

**Corollary (Multiplication is not definable).** The set $\{(x, y, z) \in \mathbb{N}^3 : x = y z\}$ is not definable in $(\mathbb{N}, 0, 1, +)$, even with parameters.

*Proof.* If $\psi(x, y, z)$ defined it, then $\exists y\, \psi(x, y, y)$ would define the set $Q$ of squares. Suppose $Q$ is ultimately periodic with $k$ and $p$. Choose $n$ with $n^2 \geq k$ and $2n + 1 > p$. Then $n^2 \in Q$, so $n^2 + p \in Q$. But $n^2 < n^2 + p < (n + 1)^2 = n^2 + 2n + 1$, so $n^2 + p$ is not a square. This contradicts the corollary on subsets of $\mathbb{N}$. $\square$

### Examples

**Example (Even numbers and residues).** The formula $\exists y\, (x = y + y)$ defines the even numbers, the linear set $0 + \mathbb{N} \cdot 2$. The formula $\exists y\, (x = y + y + y + 1)$ defines $1 + \mathbb{N} \cdot 3 = \{1, 4, 7, \dots\}$, which is periodic with $k = 0$ and $p = 3$.

**Example (The order).** The formula $\exists z\, (y = x + z)$ defines $\{(x, y) : x \leq y\}$, which is the linear set $(0, 0) + \mathbb{N}(1, 1) + \mathbb{N}(0, 1)$: $(x, x + z) = x (1, 1) + z (0, 1)$. The periods are linearly independent, so it is proper.

**Example (A numerical semigroup).** The linear set $\langle 3, 5 \rangle = \{0, 3, 5, 6, 8, 9, 10, \dots\}$ contains each $x \geq 8$, as $8 = 3 + 5$, $9 = 3 \cdot 3$ and $10 = 5 + 5$, and adding $3$ continues the pattern. So it is ultimately periodic with $k = 8$ and $p = 1$. It is defined by $\exists y \exists z\, (x = 3 \cdot y + 5 \cdot z)$.

**Counterexample (Powers of two).** The set $\{1, 2, 4, 8, \dots\}$ is not definable: if it were ultimately periodic with $k$ and $p$, take $2^n \geq \max(k, p + 1)$; then $2^n + p$ would be in the set, but $2^n < 2^n + p < 2^{n+1}$.

### Exercises

1. (A) Write a formula that defines $\{x : x \equiv 2 \pmod 5\}$ and give the set as a linear set. Hint: $\exists y\, (x = 5 \cdot y + \underline{2})$.
2. (A) Show that each finite subset of $\mathbb{N}^k$ is semilinear and definable without parameters. Hint: a point is a linear set with no periods.
3. (A) Find $k$ and $p$ for $\langle 4, 6 \rangle$. Hint: the gcd is $2$, and each even number from $4$ on is in the set.
4. (B) Prove that $\{(x, y) : y = 2x\}$ is linear and that $\{(x, y) : y = x^2\}$ is not definable. Hint: for the second set, project to the second coordinate.
5. (B) Prove that the set $\{x : x \text{ is prime}\}$ is not definable in $(\mathbb{N}, 0, 1, +)$. Hint: an ultimately periodic set with infinitely many elements contains an arithmetic progression $r + \mathbb{N} p$, and $r + r p$ is composite for $r \geq 2$.
6. (C) Prove that a subset of $\mathbb{N}$ is definable in $(\mathbb{N}, 0, 1, +)$ without parameters if and only if it is definable with parameters. Hint: each $a \in \mathbb{N}$ is the value of the numeral $\underline{a}$.

### Notes and history

Presburger proved in 1929 that the theory of $(\mathbb{N}, 0, 1, +)$ is complete and decidable, by quantifier elimination in the language with congruences modulo each $n$. Ginsburg and Spanier proved that the definable sets are the semilinear sets, and the file cites their papers and the work of Eilenberg and Schützenberger on rational sets in commutative monoids. Multiplication changes the picture completely: the definable sets of $(\mathbb{N}, +, \cdot)$ include each computably enumerable set, and Gödel's incompleteness theorem of 1931 applies to its theory.
