# Monotone functions and order maps

A function between two orders is monotone when it keeps the order. This chapter studies the maps that are compatible with `≤`, first as properties of a function and then as bundled structures. The first section defines the predicates `Monotone`, `Antitone`, `StrictMono` and `StrictAnti`, and their forms on a set, such as `MonotoneOn`. It proves that the predicates are closed under composition, that a strictly monotone map on a linear order is injective and reflects the order, and that a function on `ℕ` is monotone when it is monotone from each `n` to `n + 1`. The second section defines the bundled maps: the order homomorphisms `α →o β`, the order embeddings `α ↪o β` and the order isomorphisms `α ≃o β`. It shows that a bijective monotone map is not always an isomorphism, that a strictly monotone surjection from a linear order is one, and that an isomorphism carries each order property, for example least upper bounds, from one order to the other. The third section studies initial segments and principal segments, the order embeddings whose range is a lower set, and proves that two well-orders are always comparable by such a map.

The chapter needs the first chapter of this volume: preorders, partial orders, linear orders, bounds and the dual order. The bundled maps of the second section use the relation maps `RelHom`, `RelEmbedding` and `RelIso` of Mathlib, and the section explains the parts of them that it uses.

The later chapters use these maps all the time. The chapter on complete lattices proves the Knaster-Tarski theorem for an order homomorphism `α →o α`. The chapter on Galois connections studies pairs of monotone maps in opposite directions. Each isomorphism of orders in the volume, for example the map from an order to its dual, is an `OrderIso`.
